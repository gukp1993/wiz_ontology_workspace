模型设置

模型配置分为「供应商 → 模型」两级：供应商持有接口地址与 API Key（加密保存、只写不读回），模型挂在供应商下，同一供应商可启用多个模型。配置为账号级，供函数编排、本体构建等全工作台使用。

默认模型 智谱 BigModel · glm-4.7 · 思考档位：medium 未明确指定模型的节点与本体构建使用此默认。

提示：禁用的供应商 / 模型保留配置但不出现在各处选择列表；被编排节点引用时报「已禁用」而非「不存在」。
