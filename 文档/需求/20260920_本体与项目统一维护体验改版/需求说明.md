整合依据：

- [项目模块配置维护改版](../20260920_项目模块配置维护改版/需求说明.md)：P01～P07已出方案，尚未实施。

## 5. 统一交互规范

### 5.1 按任务统一，不按容器强行统一

| 任务 | 呈现方式 | 约束 |
|---|---|---|
| 找对象、属性或映射 | 左侧对象索引＋右侧详情；资产用表格 | 索引不改成多层卡片；搜索无结果不等于资产为空 |
| 快速看完整定义 | 行内展开或只读详情抽屉 | 键盘可操作，不仅靠hover；不混入保存表单 |
| 编辑完整定义/配置 | 沿用现有表单页 | 显示所属对象、来源入口；返回原位置 |
| 看使用位置 | 按业务位置分组的列表/抽屉 | 业务名称＋原因＋定位，技术ID仅辅助 |
| 高影响修改 | 保存前一次确认 | 列具体变更，取消保留输入；不重复弹相同确认 |
| 错误修复 | 位置、原因、处理方法＋去处理 | 返回原清单；不能跳到笼统菜单就算定位成功 |

不要求所有页面三个列名完全一样。本体强调定义及共享关系，项目强调说明与具体配置；保留各自必要列，统一工具栏、表头、行高、文本层级、操作位置、空态和反馈方式。

### 5.2 内容与操作层次

- 名称为一级，业务定义/来源摘要为二级；主要编辑操作明确可见。
- 每行保留一个主要操作；低频动作可收“更多”。不将关键操作隐藏到悬浮才能出现。
- 描述最多显示约两行，并提供“展开/收起”或查看全文；代码、长标识可换行，不能撑出操作区。
- 链接数量关系给具体例子：多个储能簇属于一个设备；反向阅读是设备包含簇。
- 共享选择保持两种能力，解释“引用后同步更新”“复制后独立维护”。不增加全局强制默认共享规则。
- 更多工具移除重复的动作定义和旧版映射展示入口，旧hash/深链继续正确跳转；不批量删除历史兼容代码。

### 5.3 返回上下文

记录来源工作区/资产ID/对象ID/页签/筛选/滚动，画布还保留缩放、平移与节点位置。详情编辑保存或取消后恢复；用户改变了有效数据时刷新内容但不重置浏览位置。

若原对象被删除或筛选不包含目标：解释原因并提供清除筛选/回列表，不静默选另一个对象。图谱仅在目标视口外时最小平移，不自动重排或缩放。

跨页先处理未保存表单；确认放弃或继续编辑沿用现有守卫。清洁表单返回无需额外确认。只读查看使用位置不触发编辑保存。

### 5.4 确认的边界

仅对高影响含义修改、破坏引用的技术变化、删除等使用确认。仅改显示名、格式或非语义排版不增加重型确认。业务定义文本变化无法自动可靠判定语义是否相同，沿用当前保守影响提示，不引入LLM语义分类。

确认绑定当前编辑内容与实际依赖；基线/依赖改变后旧确认失效。阻断与确认分开：不能通过勾选“我知道”绕过失效引用或强制删除。

## 6. 本体侧详细需求

### O01 共享影响确认（复用现有实施）

共享定义编辑显示引用数与查看位置。高影响变更的确认展示字段前后值、对象→属性清单，并说明仅影响当前草稿。共享属性引用保持只读，提供编辑共享定义或转为私有。

取消确认保留输入；取消整个编辑不落库。普通名称变更不显示高影响弹窗。无变化不制造新修订。保存失败或CAS冲突后重新取得基线，不能重复使用旧勾选。

本次不新增发布影响审批、不切换项目引用。原型的类型枚举只是示例，正式版保留项目已支持的完整数据类型及精度兼容。

### O02 统一操作含义（复用现有实施）

| 操作 | 结果 | 保护 |
|---|---|---|
| 移除对象的共享属性 | 移除这一对象的属性引用；库定义与其他对象保留 | 对象属性存在下游依赖时阻断 |
| 转为私有 | 保留对象属性ID与当前内容，解除共享 | 不修改共享库及其他引用 |
| 删除共享/规则/动作定义 | 删除当前草稿库定义 | 有当前草稿依赖阻断，列具体位置 |
| 移除对象规则/动作关联 | 仅解除当前关联 | 定义及其他关联保留 |
| 删除链接 | 删除同一链接定义及两个阅读方向 | 依赖规则各入口一致 |
| 删除对象 | 保持现有阻断策略 | 不增加级联清理或静默解除动作关联 |

列表、详情、图谱快捷键及保留命令遵循同一判断；批量一项失败不得部分提交。已发布历史引用不使草稿定义永远无法删除。后端维护引用完整性，不能只靠按钮防护。

### O03 / O04 编辑连续性与阅读

先验证已有返回链路，再补缺陷，不重建已经统一的表单。对象详情的属性、链接、规则、动作均可就地读取完整说明；进入共享库或规则库编辑时显示来源，允许返回。

当前对象被搜索隐藏时保留详情并明确提示，给“清除搜索”，不跳到别的对象。列表与图谱是同一工作区两个视图，增强切换识别但不另建菜单。原型只模拟视图返回，不代表画布能力重写。

本体新增对象/属性沿用现有功能；本原型不覆盖每个创建表单，不据此删除现有新增入口或字段。

## 7. 项目侧详细需求

### 7.1 P01 / P02：状态与编辑主路径

项目概览显示引用本体及固定版本、映射概况与待处理项；统计失败显示“无法读取/—”，不能显示0。未采用属性不进入强制完成分母。不要强制先建连接，登记实例加说明也能先建设。

映射列表显示名称、类型/关系、说明或配置摘要、主要状态、编辑。对象/属性/链接/动作描述都为一个textarea，位于结构化配置之前，可折叠；没有模式开关、变量插入和附加说明工具条。简单字段映射无需强制填写说明。

**相对上一版修正：列表承担浏览摘要，点击编辑后默认展开当前具体配置；新建、首次配置、问题定位也展开。** 用户可手动折叠；切换类型只显示相关字段。说明依旧在前，不再把“配置默认折叠”作为全场景规则。

| 情况 | 主要呈现 | 详细依据 |
|---|---|---|
| 没有说明也没有来源 | 尚未配置 | 是否阻断取决于实际范围，不默认强制 |
| 只有说明 | 仅填写说明 | 不表示被解析或执行过 |
| 配置读取失败 | 无法确认 | 原数据保留；重试，不伪装无配置 |
| 当前检查有阻断 | 需修正＋首条原因 | 展开全部问题及定位 |
| 没有当前有效检查 | 待检查 | 辅助说明是尚未检查还是旧结果过期 |
| 对当前基线检查通过 | 配置检查通过 | 不等于真实取值或设备操作成功 |

多个事实不要堆成多个主标签：说明存在由摘要表达；历史问题可查看，但过期时不能冒充当前已确认问题。连接状态与项目检查分开展示。

有效检查对应项目修订、本体固定引用及实际涉及的编排/目录配置基线。相关内容改变即失效；本期允许整份报告失效后手动重查，不要求增量引擎。未保存表单不能冒用已保存项目的通过状态。

### 7.2 P03：对象实例来源变更

用户文案区分数据库记录与项目登记实例。登记实例用于无单表来源的系统等虚拟对象，只解决身份，不自动计算成员及汇总。

改变连接、表、主键或来源方式时，保存前展示受影响的直接字段、实例参数、链接端点、动作绑定。普通对象说明编辑不弹该确认。

确认后保留原绑定并显示具体待修复项，不清空描述或自动同名替换。若现有协议不能保存该失效中间态，说明冲突、保留表单并允许先处理相关项；不能以静默删配置作为退路。本次不加入自动集合推断。

### 7.3 P04：连接状态与影响

凭据是否配置、最近连通测试、目录刷新时间分别表达。名称修改不让连通结果无故失效；技术地址或凭据变化使测试过期，数据库/schema变化使目录需重读。

连接探测与刷新显式触发，不自动执行属性SQL。密码只写不回显，连接信息与凭据各自保存失败需准确反馈，不用一个“成功”掩盖部分失败。

使用位置按稳定引用解析。范围至少覆盖现有对象来源、属性和项目实现；编排作用域须核对后纳入，不能只按字符串匹配或未知当无引用。删除前服务端复核；查询失败不放行。

目录刷新发现字段移除或类型变化时，保留原配置、显示具体影响并定位。不能把capacity换成相似字段。无业务字段目录的Redis不强造表结构状态。

### 7.4 P05：绑定与编排衔接

绑定时展示所选编排实际输入/输出；稳定ID关联，名称只用于显示。示例设备SOC输入storageId绑定当前设备ID；采样SOC使用表名、属性名、实例ID及时间范围。示例不固化为所有编排的强制参数。

从属性进入已有编排编辑器，保存原来源位置；回来后重读声明，输入输出变化则重新检查，不能按名称猜测重绑。未保存绑定先通过现有守卫处理。

编排为账号资产，可按当前项目引用筛选但不能隐藏其他合法资产。现有节点测试与片段测试不动。项目发布未冻结编排内容时如实说明；不增加一个假的“固定修订”标记。

### 7.5 P06：诊断与项目发布

按配置位置归组，同一诊断只展示一次。主界面分阻断、提醒及未采用项，明确检查失败/过期；详细技术字段可折叠。去重依据稳定定位和问题类型，不能仅比较中文字符串。

“去处理”进入准确对象/页签/表单，带来处与问题原因；保存后返回原报告并重新检查。取消不消除错误。动作、链接、项目参数不能误跳到属性表单。

发布前处理保存、获取最新配置并由后端重验。只有当前有效检查无阻断才可继续；状态冲突或服务失败保留输入，不假报成功。已有幂等发布规则保留。

明确发布的是项目配置及本体固定引用，不是设备下发或真实取值验证。仅说明及未采用项按现有校验范围处理，不要求配置整个本体。

### 7.6 P07：更新本体引用

沿用现有比较与确认。比较对象是当前固定发布版本与目标已发布版本；未发布草稿只可作为独立次要信息，不能混入目标比较。

列可保留、新增未配置、类型或字段需修正、失效引用，覆盖对象/属性/链接/动作及说明。相同稳定ID的合法配置保留，删除定义对应的原配置保留供处理；跨本体不能按中文名自动迁移。

切换只改项目草稿，不自动发布。比较绑定项目修订和目标版本，内容变化或409后重新比较；取消/失败不假报已升级。确认成功后进入待修复项，不宣称所有配置有效。本体版本恢复仍延期。

## 9. 视觉与原型约束

沿用当前工作台的浅色背景、白色侧栏/内容面板、蓝色选中和主操作、细边框、列表/详情布局，不另换视觉体系。错误红色、提醒暖色、保存结果绿色，必须配文字，不仅靠颜色。

原型顶部提供“改动总览”“显示/隐藏标注”“重置”。总览可跳转11项改动；页内标明编号、变化、状态。原型编号、实施阶段、无网络提示与模拟失败开关均属于评审工具，**不能照搬到正式产品页面**。

图谱只是节点/返回路径示意；连接目录用简化输入；编排仅演示声明与返回；辅助工具、创建表单、本体发布保持既有功能，不在原型重复建设。示例不定义正式数据协议。

所有示例只在内存，刷新重置；不含真实连接、密钥、用户资产，无网络请求。原型状态通过不等于正式接口、权限、并发、响应式或画布已通过验收。

1440/1024/768应保证关键按钮可达；窄屏可将对象索引移至详情上方，表格横滚，不把操作挤出不可达区。弹窗内部滚动，底部按钮可达，键盘可关闭且正式版关闭后焦点回触发项。具体间距沿用现有设计变量，不另造尺寸体系。
