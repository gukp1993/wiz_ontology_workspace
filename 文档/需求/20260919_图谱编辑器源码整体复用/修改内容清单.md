## 3. 旧功能 → 当前入口 对照（能力冻结表摘要）

| 旧入口 | 处理 | 当前等价入口 |
|---|---|---|
| 图谱管理（选择/新建/删除图谱） | 对接现有 | 「本体」按钮：本体列表切换/新建（App switchOntology/createOntologyNamed，未保存守卫保留）；本体删除工作台未提供，未迁入 |
| 版本管理 / 保存版本 / 另存为新版本 / 版本历史 | 对接现有 | 「发布」按钮与「发布…」→ 当前「本体校验与发布」页；保存=草稿协调器（Ctrl/⌘+S → commit-now）；修订历史在该页维护 |
| 预览 / 多图谱预览 | 对接现有 | 单图=最新发布版本只读预览（无发布时引导）；多图=各本体发布版本多选并列只读（ID 含本体+版本身份，不串图） |
| 新建/编辑/删除节点、连线模式、批量连线、删除、撤销/重做 | 迁入 | 交互逐行保留；领域命令经 bridge 走 before-change/changed/保存协调器；删除保护（graphReferences/规则与动作引用/共享引用计数）与当前建模约束一致 |
| 导入Excel / 导出模板 | 对接现有 | 跳转工作概览「导入本体」（现有 Excel 服务与模板） |
| 导入 jsonId | **移除（登记）** | 当前无 jsonId 导入服务；完整迁移走「设置→配置迁移」 |
| 导出 jsonId | 迁入+约束 | 客户端导出；含动作/私有属性/共享引用/时间序列等不可表达内容时**默认阻止并显示损失清单**（需求 §2） |
| 导入坐标 / 导出图谱包 | 迁入 | 坐标按 lg: 稳定 ID 匹配（兼容旧 czy: 序号一次映射，登记）；图谱包=ZIP（坐标 JSON + 离线预览 HTML，断网可查看、无凭据） |
| MCP / 问数预览 / 用户徽标（登录登出） | **移除（登记）** | 旧应用外围服务，不属本期范围；账号由工作台顶栏承担 |
| 3 秒自动保存 / 版本快照切换前自动保存 | **切断** | 一律走当前保存协调器（900ms touch 合并 + commit-now + 409 冲突流），无第二套保存器 |

## 6. 已知限制（如实登记）

1. 批量连线面板沿用旧「同源同目标任一方向已连即去重」策略；对象间同名平行链接经对象表单仍可建立（投影支持）。
2. 旧 `czy:` 坐标文件仅做一次兼容映射（对象→entity、共享/私有按投影顺序合用 attribute、规则→rule；动作无旧映射）；主匹配按 `lg:` 稳定 ID。
3. 本体删除、jsonId 导入无当前等价服务，未迁入（走配置迁移）；未发现其他被静默削减的旧功能。
4. 自动整理由旧三类带推广为五带等距锚点，中带 1/4~3/4 收敛循环未保留（三类图谱行为与旧版接近；确定性不变）。
