日期：2026-09-19。状态：方案待实施。本轮不修改工作台业务代码或真实数据。

配套：[交互原型](交互原型_v1.html) · [开发计划](开发计划.md) · [执行指令](执行指令.md)。原型使用模拟数据；本文是行为与边界的完整依据。

## 1. 目标与范围

入口保持「本体 → 对象建模 → 本体图谱」。将现有只读图谱升级成便于浏览、查找、理解关系和整理布局的工作区。支持五类节点：对象、共享属性、私有属性、业务规则、动作；业务对象间链接继续表示为有向边。

本期交付：真实图谱完整投影、搜索定位、多选与拖动、邻域查看、自动布局及布局撤销、可收起面板、画布最大化、准确详情、定义导航、账号/本体隔离的本地视图记忆。

本期不做：直接在图上新建/删除定义、自由连线、批量改属性、执行动作、推导规则依赖、跨本体合并画布、数据库表/实例图谱、PNG/坐标导入导出、离线预览包、新增发布机制。旧项目的完整图编辑能力不全部照搬；“打开定义”进入现有页面编辑，沿用原保存机制。

## 3. 当前实现需先修正的问题

当前 `frontend/src/ontology/OntologyGraph.vue` 的代码事实：

1. `pushEdge` 用起点+终点+名称去重，且拒绝 source===target：会遗漏不同稳定ID的平行链接和合法自关联。新投影必须以定义/引用身份区分，不拿名称当ID。
2. `modelStamp` 只监听节点/边数量和关系名称：改名称、业务定义、属性类型，或等数量替换节点，可能不刷新现有图与详情。
3. 搜索接入 baseVis，非命中节点消失；与注释里的“搜索高亮”不一致。
4. “全部显示”不清空搜索；清除选中可能留下详情。筛选、选中、详情、邻域需要统一状态转换。
5. `closure` 只收集首次访问新节点时的边，存在平行边/环时高亮可能漏边。节点可达计算与诱导子图边收集须分开。
6. 位置缓存直接用 localStorage，未使用 `app/auth.ts` 账号偏好封装；key在setup计算后不随本体ID改变。
7. 每次数量变化销毁重建并fit，丢失视口与选中；右栏调整未显式协调cy.resize；小屏三栏堆成上下长页。
8. `window.__ogCy` 调试引用、延时与拖宽事件需检查卸载清理，不把生命周期残留带入新版。

以上作为代码审阅发现纳入验收，不需要扩展到全站重构。

## 4. 页面与视觉

沿用当前工作台深色主侧栏、蓝色主色、白色面板、浅灰边框；节点保持现有五类颜色和形状，同时显示类型文字，不能仅靠颜色理解。

- 一行主工具栏：左侧搜索；选择/移动；整理布局下拉；布局撤销/重做。右侧筛选、详情、最大化、帮助。次要按钮在窄屏收进“更多”。
- 左筛选栏宽200–240px，可收起；包含节点类型、关系类别、显示数量、恢复全部。
- 中央画布占剩余全部高度；左上仅一行状态“显示x/y节点、x/y关系”；右下角缩放条“- / 百分比 / + / 适应窗口”；上方仅在邻域态出现可关闭的状态条。
- 右详情宽320px默认、可调280–480px，长说明在详情内滚动。未选中时默认收起，第一次单选自动展开；用户主动关闭后，单击只选中、双击或详情按钮再展开。
- 窗口1440宽：三栏可见；1280宽：默认收起筛选；1024宽：筛选与详情采用覆盖抽屉且互斥，不能把画布挤到420px以下或变成页面下方一块；768宽：工具栏折叠、画布仍可平移和缩放。
- “最大化画布”扩大到工作台内容区（隐藏工作台侧栏/顶栏的视觉占位，保留画布工具栏）；不用浏览器系统全屏权限。退出后恢复原界面，不改导航、本体或项目。

## 5. 操作规格

### 5.1 选择与移动

| 操作 | 行为 |
|---|---|
| 单击节点/边 | 单选并更新详情；**不自动裁掉其他节点、不自动重排** |
| 单击空白 | 清除选择和详情；在邻域模式中不退出邻域中心，退出由专门按钮或Esc完成 |
| Shift+单击节点 | 增减选择；多选仅针对节点；最后取消时恢复未选态 |
| 选择模式拖空白 | 矩形框选可见节点，默认替换；Shift框选为追加 |
| 移动模式拖空白 | 平移；Shift+拖空白临时框选 |
| 拖节点 | 移动当前节点；选中多节点时一起移动。一轮拖动只记一个布局撤销点 |
| 按住Space拖空白 | 临时平移；松开恢复原工具。输入框/编辑区内不触发 |
| 双击节点 | 定位并展开详情，不修改定义、不触发表单保存 |
| 双击边 | 展开关系详情。多条重叠边可在详情的关系列表逐条选择 |

多选详情显示数量与类型计数，操作仅“定位选中”“取消选中”。不出现删除、执行动作或批量修改。平行边弧度错开，自关联使用环线；悬浮边显示名称与两端对象，不以悬浮作为唯一阅读方式。

### 5.2 搜索

搜索节点显示名称及对象别名；不检索长规则正文。忽略大小写和首尾空格。输入只高亮命中，不重排、不改变筛选、不隐藏非命中。显示命中数及前20条结果，超出分页或滚动加载；每条带类型、名称及必要的所属对象，区分同名属性。

Enter定位当前结果，↑↓移动结果焦点，Esc关闭结果列表，Tab保留原生焦点顺序；不照搬旧版劫持Tab。定位缩放上限1.6倍，避免小节点被放到整屏。结果被筛选隐藏时显示“被筛选隐藏”，提供“显示并定位”：**显式**打开其类型、移除对应手动隐藏（本期没有单节点隐藏则不实现该项），若不在当前邻域先退出邻域；不修改关系筛选。清空搜索仅清高亮与列表，保留布局和筛选。

### 5.3 邻域查看

单选节点后显示“查看关联”，默认1跳、双向、原位置；可选1跳/2跳/全部可达，方向“相关（双向）/流入/流出”。这些词只表示图上的边方向，不意味着业务数据血缘或函数依赖。

仅沿已勾选关系类型且两端类型可见的边遍历；双向为无向BFS，流入/流出为有向BFS；全可达使用visited防环。先求节点集合，再保留集合内全部符合筛选的边，包括平行边、自关联边，不能仅画BFS树。

邻域态提供“原位置/环形展开”。环形是临时阅读位置，不覆盖全图缓存；退出恢复进入前全图坐标、视口和仍存在的选择。临时拖动和撤销只作用于临时布局；不进入全图撤销栈。邻域中心固定，单击另一个节点只看详情，“以此为中心”才更换中心。筛选隐藏中心时退出邻域并提示原因。

### 5.4 布局与缩放

- 整理布局两种：**按类型排列（默认）**、**按关联聚集**。仅显式点击执行，搜索、选择、筛选、拖宽面板不能触发布局。
- 按类型排列：对象/属性/规则与动作分组，组内按直接关联对象排序、名称和稳定ID做确定性tie-break；每列最多20个节点，超过增加子列。规则与动作分组内可分带。孤立节点独立尾部，不散到巨大空白范围。
- 按关联聚集：按连通分量摆放，分量内确定性分层或Cytoscape现有布局实现；同一输入结果稳定，不为随机布局加重依赖。
- 整理作用于当前可见子图，隐藏节点坐标保持不变；恢复全部后不自动整理，用户可主动整理全部。
- 布局撤销/重做最多30步：仅拖动/自动整理/重置位置；缓存坐标和对应视口。普通平移缩放不产生撤销点；不会回退本体业务定义。数据增删后清空局部布局历史并提示，避免旧记录复活已删节点；改名/类型/说明保留历史。
- “适应窗口”只适配可见节点边界，不取消筛选/搜索/邻域；“显示全部”清除搜索、筛选限制、邻域和选择并fit，保留节点手动位置；“重置位置”是明确独立项，重新默认排布且可撤销，不能和显示全部混用。
- 缩放范围10%–400%，按钮步长约1.2，滚轮以鼠标位置为中心；100%回到比例1并保持视口中心；定位选中适配可见选中集合。
- 0节点/全部过滤/无搜索命中使用不同提示；空集合fit不得NaN或抛错。

### 5.5 详情与跳转

节点详情展示对应现有业务定义字段：对象名称/别名/定义；属性类型/观测值类型/显示格式/共享引用数或所属对象；规则定义/内容/输出；动作定义/效果。保留 `reviewNote` 待确认提示（如存在），不新增业务字段。长文本可复制，禁止以HTML执行。

关系详情显示来源类型（对象链接/共享引用/私有属性归属/规则关联/动作关联）、两端、关系名、链接基数及反向名称、说明。共享引用边附实际对象属性定义ID用于定位，不能只知道共享属性ID。

“打开定义”：对象→对象详情；私有属性→所属对象的属性定位；共享属性→共享属性库；规则→业务规则；动作→动作定义；对象链接→起点对象链接页签并定位稳定ID。归属/关联边→对象对应页签；共享引用允许分别打开对象属性或共享定义。优先复用现有 focus/navigation 协议，必要时只添加可选的画布返回上下文，不造第二套表单。

往返恢复同本体的画布筛选、位置、视口、选择、邻域（目标仍存在时）；编辑重命名后立即更新画布与详情。目标已删除则清空选择并提示，不能保留幽灵详情。浏览器前进/后退不重复打开编辑页。

### 5.6 键盘

仅画布有焦点且未打开菜单/抽屉表单时：F定位选中（无选中则fit可见），+/-缩放，Shift+F适应窗口，Space临时平移，Esc按层关闭菜单→退出邻域→取消选择→退出最大化，?显示帮助。Ctrl/⌘+Z与Shift+Z仅撤销/重做布局并阻止冒泡到全局本体撤销。输入框、textarea、contenteditable内全部让给文本编辑；不拦截系统Ctrl/⌘+F，不接管Delete/Backspace删除定义，不增加画布保存快捷键。

## 6. 数据和状态约定

1. 读现有 `state.ontology['@graph']` 和 `workflow.businessRules/actions/*Associations`，不读导入来源扩展图作为权威。未明确建模的规则依赖不自动推断上图。
2. 对象与属性使用现有完整ID；Cytoscape内部ID须命名空间化并保留 domainId/kind，避免规则和动作恰有同名ID碰撞。每条业务链接用link定义ID，改显示名不变；派生引用边优先用对象属性ID，规则/动作关联用类型+双方ID复合键（无独立ID时）。去重只针对完全重复的同一引用。
3. 每个共享属性只显示一个定义节点；多个对象的引用各自为边。私有属性即使同名也为独立节点。悬空引用不绘制假节点，显示可定位到原定义的异常计数；数据层不静默修复。
4. 图谱增量更新基于稳定ID与相关显示字段（名称、类型、端点、说明、reviewNote、引用等），不只比数量，也不深监听整个工作台导致无关项目变化重建。
5. 布局与视图仅本机偏好，经 `prefGet/prefSet` 隔离账号与本体：逻辑key建议 `ontologyGraph:v2:<ontologyId>`，实际前缀使用现有账号封装。已登录且本体ID非空才读写；旧无账号 `ont-graph:*` 缓存不自动迁移，防跨账号读取。
6. 缓存含schemaVersion、positions、viewport、筛选、面板状态/宽度、当前选择；邻域临时坐标不持久化，全图基础位置才可保存。刷新可恢复邻域参数并重新派生临时布局。历史栈仅内存；注销清空内存。
7. 坐标需有限数字，zoom夹紧，未知ID剔除；损坏或不可用localStorage退到会话内并提示一次。缓存写入防抖200–500ms，切换/卸载前flush到**旧账号旧本体key**，随后清理监听、ResizeObserver、RAF、timer和debug引用。
8. 全部画布操作不emit changed/before-change、不调用save/publish、不更新revision；实际编辑表单走原保存协调器。
9. 本期不新增数据库表/接口、不改本体协议、发布快照或配置迁移包。画布本机偏好不随配置迁移。
