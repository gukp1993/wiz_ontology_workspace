# 微软列表／详情布局原型

日期：2026-09-17　版本：V1　状态：布局方案待用户评审，未授权替换正式工作台。

配套：[交互原型](交互原型_v1.html)｜[开发计划](开发计划.md)｜[执行指令](执行指令.md)

## 目的

解决对象类型多时左侧卡片占空间、查找困难和详情拥挤的问题。以对象建模为示范，设计可复用于属性、动作等管理页面的列表／详情布局。保留管理后台风格。

## 微软规范与本项目适配

依据：[Microsoft List/details pattern](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/list-details)。其核心是列表选择更新详情；空间足够时并列，空间不足时只显示列表或详情，详情提供返回。

文档面向 Windows 应用，给出的 epx 建议不能直接当成包含全局侧栏的网页断点。本原型使用浏览器宽度 1000px 切换单栏，考虑 190px 侧栏和业务表格宽度；这是项目设计值，不是微软强制规定。分页、收藏、每页 12 项也是项目方案。

## 页面结构

1. 全局侧栏：只放模块导航，不放对象卡片。
2. 顶栏：本体上下文和原型状态。
3. 页面标题及命令栏：对象建模、自适应／单页详情、新建对象。
4. 内容：宽屏左侧紧凑对象列表（约 290px）和右侧详情；两区独立滚动。
5. 详情：对象名称、业务定义、编辑定义、收藏、快速切换；属性／链接／动作页签。
6. 窄屏：列表进入详情，显示返回按钮；保留搜索、页码、排序和列表位置。

## 可交互范围

- 64 个内存示例对象类型，其中 46 个明确标记为示例类型，不冒充设备实例。
- 全量名称／定义搜索、清空、名称排序、收藏筛选、12 项分页、对象选中态。
- 快速切换弹窗搜索全部类型，必要时清除妨碍定位的列表筛选并定位页码。
- 属性表格、属性搜索、只读属性详情；链接页示例跳转；动作页示例定义。
- 对象名称与定义的新建、编辑、必填验证、取消及未保存退出提示，只写页面内存。
- 显式“单页详情”选项便于宽屏比较单栏和并列体验。
- 按钮 Tab/Enter/Space，列表方向键移动焦点；弹窗使用原生 dialog。

非范围：真实保存／发布、属性共享转私有、动作功能开发、图谱新功能、所有业务页面重构。未实现入口点击显示说明，不伪装完成。原型没有后端请求、持久化和真实数据。

## 交互约定

- 搜索覆盖全部数据，不能只过滤当前分页。
- 筛选没有当前选中对象时，不暗中换对象；详情提示对象不在筛选结果。
- 翻页保留详情，直到明确选择另一个对象。
- 单栏返回保留列表状态；直接跨对象跳转则定位目标所在页。
- 编辑用显式保存与取消；不因失焦意外保存。
- 原型状态刷新重置，不展示“已保存到工作台”。

## 评审要点

先比较并列与单页详情的便利性，再确认默认布局。确认列表宽度、对象摘要信息、搜索与分页、顶部命令密度。共享属性是否取消、动作配置范围不在本次决定。

## 验收标准

64 项可搜索到末页对象；分页不丢选择；切换窄屏仍可返回；长名称不撑破目录；表格在小屏可横向滚动；编辑保存／取消互不混淆；对象切换不串用属性与动作。正式实施还需验证已有保存、深链、撤销与画布行为不回归。

### 新建与切换

左上工作区切换为本体／项目；下方当前本体或项目名称是可搜索切换器，底部提供新建。小屏提供“菜单／切换”按钮。

- 新建本体：只填名称，创建空白定义，不复制储能示例；有创建第一个对象的入口。
- 新建项目：项目名称、已发布本体、对应版本；不能引用未发布本体。
- 本体发布在页面内创建对象快照；项目对象映射读取其固定版本，本体草稿新增对象不会立即出现在项目映射中。
- 版本引用比较仅统计对象增删，不冒充正式兼容分析；用户确认后只更换项目引用，保留配置且不自动发布。

### 模拟边界与布局精度

所有数据只在内存中，刷新复原。没有 API 请求、业务 SQL、设备控制、真实连通测试或密码存储。

链接页及画布使用少量固定关系展示布局，不等同完整图编辑器；原型各菜单是交互深度示意，不替换已有 SQL 多步模板、业务规则完整协议或函数编排 DAG 实现。辅助历史页有意只读。

连接测试按钮明确写“模拟测试连通”。发布按钮明确写“模拟发布版本”。发布基础检查不等于生产发布校验。复制属性演示只复制元数据，不意味着已决定迁移共享属性。项目内新建、配置和刷新均不得回写真实工作台。

正式落地必须复用稳定引用及现有业务协议，不能采用原型中的名称／数组索引作为真实存储键。跨对象动作绑定与本体版本兼容规则仍以各独立业务需求为准。
