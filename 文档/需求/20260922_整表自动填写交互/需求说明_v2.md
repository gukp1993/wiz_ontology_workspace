# 自动填写 v2：需求说明

日期：2026-09-23。状态：设计交付，**未授权实施或合并**。本文件是现有自动填写的改版基准；[局部交互原型](交互原型_v2.html)只演示“新建对象”，其余已接入表单沿用同一规则。v1 中未与本文件冲突的权限、候选、草稿、撤销和保存约束继续有效。

## 1. 目标与范围

用户可一直手填；需要帮助时打开当前表单的“自动填写”，输入一句名称或较长业务说明，系统填写**能合理生成的字段**，而非把完整内容反问给用户。对象输入“储能系统”应一次填入“对象名称”和可编辑的“业务定义”草稿。

本期覆盖现有本体对象、属性、链接、规则、动作及项目实例识别、属性来源、链接映射、动作接口绑定表单；不新增表单、自动创建关联资产、执行 SQL/接口、自动保存或发布。不做每页模型下拉、提示词配置后台、聊天历史。

## 2. 填写规则

采用**通用提示词＋表单契约＋当前上下文＋服务端校验**，不为每个页面复制一套提示词。表单契约给每个可填字段声明一种策略：

| 策略 | 行为 | 例子 |
|---|---|---|
| `draft` | 可根据用户主题及已知本体语义生成可编辑草稿；不虚构项目事实 | 对象/属性业务定义、一般说明 |
| `grounded` | 仅依据用户明确输入或可信上下文填写；不明则针对性追问 | 计算口径、接口语义、匹配规则 |
| `candidate` | 只能从当前账号有权访问的候选中选，后端核验归属 | 对象引用、连接、表、字段、编排 |
| `system` | 不发给模型、不允许回填 | 内部 ID、密钥、派生字段 |

“用户原话”用于证明**用户要求填写该字段**，不意味着生成的定义逐字来自用户。服务端只允许 `draft` 字段做这种生成；不能因此放宽 `grounded`/`candidate` 的事实约束。定义写得中性、简短、可修改；设备范围、公式、数据库字段等未确认内容不作为既定事实。只有确实无法安全填写的字段才提问，不能要求用户先把“业务定义”全文写出来。

空字段优先填；已有值仅在用户明确要求修改时覆盖，未提及内容及未知扩展保持原样。类型联动、原子组、引用所属关系在草稿副本上校验后一次写回；清空及会丢弃已有配置的来源切换仍需明确授权。模型输出不是权限或有效性证明，密钥和业务记录不出网。

## 3. 交互

1. 默认是原手工表单；页头次要入口“✦ 自动填写”。打开右侧栏，显示当前表单、一个短提示词输入框和“生成并填入表单”。桌面与表单并排且允许继续查看/编辑表单；窄屏改带遮罩侧栏。
2. 侧栏只读显示本次自动填写所用模型及思考状态，**不在表单页选或改模型**。模型用途配置放在「设置 → 模型设置」；未配置时保留输入并引导去设置。
3. 生成中禁重复提交，显示实际等待时间。若取消操作仅忽略迟到结果，按钮写“停止等待”；只有真实终止上游请求时才写“取消生成”。手改、切目标或契约变化时，旧响应不得写入。
4. 成功后直接填当前本地草稿，不保存；无待补项则收起侧栏。字段高亮，状态列出实际字段名，如“已填写对象名称、业务定义，尚未保存”，可查看改动、撤销本轮。手改后不得一键撤销并覆盖手改。
5. 严格字段缺信息时先填独立合法内容，再用中文字段名指出具体缺项和补充问题；不要显示 `comment` 等内部 key。错误、超时、无变更保留提示词和表单，提供重试。检查/解释仍为次要只读帮助。

## 4. 自动填写专用模型

在模型设置增加“用途配置”：**自动填写模型**从当前账号已配置的模型中选择；**思考模式**选“跟随模型配置/关闭思考”。复用已有端点与密钥，不复制提供方配置，也不改账号默认模型。该用途配置作用于自动填写侧栏的填表、检查和解释请求；其他编排/计算请求维持原模型行为。

按账号保存用途配置。尚未指定时沿用当前账号默认模型，兼容已有用户；明确指定的模型被删除或不可用时提示重新选择，不静默改用其他模型。仅在提供方明确支持关闭思考时提供该选项，服务端也校验；当前 GLM `bigmodel.cn` 可按现有协议发送禁用参数。一次生成只发一次模型请求，除非用户补答或主动重试；分别记录模型耗时与服务端总耗时，界面不承诺一定“秒级返回”。模型连接配置仍只写入 API Key、不回显。

## 5. 验收

- 新建对象输入“储能系统”→一次生成名称和业务定义，不追问定义全文；内容可编辑，服务端修订仅在用户点“保存”后改变。
- 属性/项目映射中的连接、表、字段、公式无依据时不编造；可先填独立说明并明确待补项。现有表单的联动、引用、共享影响确认和 CAS 不退化。
- 未提及的已有内容不变；生成中手改/切目标/停止等待后，迟到响应零写入；查看修改、撤销、取消编辑行为正确。
- “自动填写”用途可独立选模型并关闭受支持模型的思考；其他功能请求不受影响；无用途配置时回退账号默认，已指定模型失效时明确报错。
- 用合成数据测试所有既有表单，运行前后端相关测试、前端构建，并在桌面/窄屏浏览器实际操作；记录模型耗时和服务端耗时，但日志不记录原始提示词、凭据或业务数据。未实测的项目标未覆盖。

原型为离线预置模拟，**不是**真实模型效果或设置页实现。正式版以真实表单契约和已授权候选生成，不能移植原型的关键词判断。
