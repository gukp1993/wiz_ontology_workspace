# 本体工作概览优化 · v1

日期：2026-09-19；仅方案与原型交付，尚未修改正式工作台。

配套：[交互原型_v1.html](交互原型_v1.html)、[开发计划.md](开发计划.md)、[执行指令.md](执行指令.md)。

## 1. 目标

工作概览是当前本体的起点与状态首页：空本体帮助开始，有内容时帮助找到资产和实际问题，发布后展示版本和使用情况。取消固定“两步流程+重复下一步建议+始终突出项目映射”的布局。

风格沿用当前实际项目：白色左侧栏、浅灰背景、白色卡片、蓝色按钮；不沿用旧深色侧栏原型，不增加渐变、插画或新的颜色体系。原型复制了 frontend/src/style.css 的当前 :root 令牌；正式实施直接使用已有变量与组件。

## 2. 状态与布局

| 状态 | 内容 |
|---|---|
| 真正空本体 | 创建第一个对象（唯一主按钮）、从 Excel 导入、下载模板文字入口、对象填写示例、发布后可供项目引用的一句话 |
| 已有资产但无对象 | 常规概览，保留资产真实数量；提示已有共享属性/规则等，可继续维护或创建对象；不是空白欢迎页 |
| 建设中 | 本体内容、当前草稿校验、版本与引用；继续建模为主按钮 |
| 已发布且草稿一致 | 内容、草稿校验、最新版本和各项目实际引用版本 |
| 已发布且草稿不同 | 同上，并显示草稿有未发布变更、查看变化；不暗示已发布内容会随草稿变化 |
| 请求加载/失败 | 各模块分别显示加载或错误，不用 0、未发布、无项目替代未知值 |

这些是派生展示状态，不新增互斥的业务状态字段。原型顶部状态切换器仅用于评审，正式产品不存在。

真正空本体须确认当前本体数据已读完、没有已发布版本，也没有已维护的对象、共享/私有属性、链接、规则、动作或需要保留的历史定义。不能只检查 objects.length=0；未能读取发布信息时不能假设未发布。

## 3. 空本体

文案：

> 开始构建你的本体
> 从一个业务对象开始，例如储能簇、储能设备；也可以通过 Excel 批量导入已有内容。

按钮：**＋ 创建第一个对象**、从 Excel 导入、下载 Excel 模板。

示例仅展示“储能簇”及其简短业务定义，创建后可按需添加属性、链接并关联规则和动作。示例不是自动填充数据；不能点击开始就生成储能资产。

- 创建直接定位并打开现有新建对象表单，不只跳到空对象列表。
- 保存成功后可进入新对象详情继续维护；返回概览时呈现真实内容状态。创建对象不得改变本体名称或 ID。
- Excel 导入、重复策略、模板保持现有能力；当前模板四类定义导入，不恢复此前回退的关系导入。
- 空态不展示零值统计大卡片、不展示重复“去处理”、不突出发布和项目映射按钮。
- 本体校验与发布侧栏入口仍保留；空态简化不修改发布规则。

## 4. 内容概览

一张卡片中的紧凑五列统计，不新增五张大色卡，不展示完成百分比。

| 名称 | 数量口径 | 点击 |
|---|---|---|
| 对象类型 | 当前草稿的对象类型定义数 | 对象建模 |
| 共享属性 | 共享库定义数 | 共享属性库 |
| 链接类型 | 当前草稿不同链接定义数；正反向共一条 | 当前本体链接清单，再定位具体对象/链接 |
| 业务规则 | 业务规则定义数 | 业务规则库 |
| 动作定义 | 动作定义数，历史定义按现有兼容口径保留 | 动作库 |

不把共享定义数、对象属性引用次数和私有属性数混成一个“属性完成数”。对象内部属性继续在对象建模中查看。统计用当前生效定义及现有适配函数，不能把外部引用节点重复计数。

链接若无全局维护页，可在概览打开轻量只读清单，再用稳定 ID 跳到已有对象链接页签；禁止为统计入口额外新建一套链接管理模块。零条时展示空清单，不能制造错误。

规则、动作、链接为零不代表不完整。问题必须来自真实校验规则，不把五类数量是否非零当成发布条件。

## 5. 校验和问题

| 状态 | 文案原则 | 操作 |
|---|---|---|
| 尚未校验 | 尚未检查当前草稿 | 开始校验 |
| 校验中 | 正在检查当前草稿 | 等待，不重复发起 |
| 有问题 | 显示元素名称、字段和具体原因 | 去填写，精确定位 |
| 通过 | 当前草稿未发现阻断问题 | 可重新校验，不说建模完成 |
| 已过期 | 草稿变更，原结果不再有效 | 重新校验 |
| 请求失败 | 暂时无法完成校验 | 重试；不显示成定义错误 |

概览不重新实现领域校验，复用已有结构化校验结果与定位适配器。示例“储能簇缺少业务定义”“实时 SOC 未选择数据类型”，实际必填条件以当前校验协议为准。不要显示只有 UUID 的问题，也不要自行编造规则要求。

建议显示前 5 个问题，其余用“查看全部 N 项问题”进入已有校验页。区分错误和警告的数量与颜色，不能把警告计为阻断。历史结果可保留，但必须显式过期，不继续作为当前待处理数或绿色通过状态。

校验结果需要绑定本体 ID、请求 generation 及校验时的内容标识。编辑期间同 revision 也可能有未保存内容，不应只比较 revision；按现有草稿变化序号/内容摘要判定。当前本体切换、导入、撤销/重做、编辑后失效；旧异步响应不得覆盖新本体。

加载失败与零错误分开；没有建议不等于已就绪。删除现有“suggestion 为 null → 定义与发布均已就绪”的推断。

## 6. 发布与项目引用

- 未发布：简洁说明及「校验与发布」次要入口，不在概览直接执行发布。
- 已发布：最新版本、真实发布时间、草稿与最新发布差异状态；如果没有比较结果，显示“尚未比较”，不能猜“无变化”。
- 项目逐项显示其实际固定引用版本，可与最新版本不同。点击查看项目应切到对应项目，再进入其概览；不要跳转到之前碰巧选中的项目。
- 最新版本不能仅依赖服务端列表末项，除非接口明确保证排序；按接口给出的发布顺序/版本元数据判断。
- 草稿差异依据规范化内容及已有发布比较能力；排除纯 UI 布局/目录缓存等非业务差异。revision 是不透明 token，不能与版本号或内容 hash 直接比相等。
- 草稿有变更时提供“查看变化”及校验发布入口，不自动发布，不自动更新项目引用。
- 无项目引用时说明暂无引用，可提供普通“查看项目”入口，不强制创建项目，不把它设为全页唯一主操作。
- 版本和项目列表分别加载/失败，某一个接口失败不抹掉已读取的另一模块结果。重试也不把草稿校验同时标为通过。

## 7. 风格和响应式

沿用当前 style.css：--bg #f6f8fa、--paper #fff、--ink #182c3e、--blue #245cdf、--line #dce4eb；卡片 10px、按钮 6px；字体继承现有系统字体。侧栏、顶栏和保存状态条复用现有 App，不重做。

主内容沿现有 20px/24px 间距；单列纵向内容。五列统计窄屏可以换行，项目表局部滚动。1440/1024/768px 检查；620px 以下沿原侧栏适配能力，不另造手机版导航。

保留明确焦点、Esc 关闭弹窗、键盘访问。原型左栏图标是模拟，正式版复用项目原图标路径。

## 8. 范围与非目标

本次只优化工作概览呈现及必要导航/状态准确性。复用新建对象、Excel、发布、项目切换与校验，不更改它们的业务规则，不新增后端执行能力，不改真实本体内容。

原型中的新建对象/缺项填写只在内存模拟；正式版从概览跳到原编辑器，不能把原型小表单替代完整表单。下载模板原型仅解释目标，不提供假文件；正式版须下载真实既有模板。

原型“开始校验”为固定示例演示，不是真实校验 API。新建、修改、校验、版本、时间、引用项目均为模拟；刷新恢复。

## 9. 验收

| 编号 | 预期 |
|---|---|
| H01 | 空本体只有一个主要开始动作，无重复建议和抢眼项目映射卡片 |
| H02 | 创建直接打开原新建表单；成功后定位对象，不改变本体身份；取消不写入 |
| H03 | 下载/导入沿用已有能力，导入后计数刷新、校验失效；不恢复关系导入 |
| H04 | 有资产无对象不是空白欢迎页；五类计数口径正确；0 动作不报错 |
| H05 | 问题描述含名称/字段，按稳定 ID 定位，警告与阻断分开 |
| H06 | 未校验/检查中/通过/过期/失败分开，无“没建议就已就绪” |
| H07 | 切换本体与编辑后旧响应不会覆盖，旧校验失效；只读浏览不触发保存 |
| H08 | 最新版本、发布时间来自真实数据；未比较不能显示草稿一致 |
| H09 | 项目分别显示真实引用版本，点击切到正确项目，不自动升级引用 |
| H10 | 版本、项目、校验加载失败独立，不填零值、不互相误恢复 |
| H11 | 样式符合当前浅色工作台；1440/1024/768px、键盘、侧栏收起可用 |
| H12 | 无用户数据改写，相关测试/build/隔离浏览器验收有证据；不把原型当完成代码 |

## 2026-09-19 补充：当前本体切换与已有本体示例

在同一份原型中，将左侧“当前本体”改为可操作下拉，提供“空本体”和“储能本体”。初次选择储能本体展示已建设的概览，包含示例定义统计（对象 5、共享属性 6、链接 4、规则 1、动作 1）、对象入口、草稿校验、发布版本和项目引用；这些数据仅为设计示例，不表示实时读取工作台。已有内容不意味着校验通过，初次进入示例显示“尚未校验”。

已有本体在统计下提供紧凑对象列表，最多展示 5 项（名称、业务定义、查看入口），超过 5 项由“查看全部对象”进入已有对象建模页，不在概览增加完整管理表单。没有对象时不显示该列表。原型展示储能簇、储能设备、储能系统、充放电计划、测试对象，点击可查看具体跳转目标。

H13：通过当前本体下拉切换，面包屑、统计、对象、校验及版本引用必须属于选中的本体，不能串用其他本体数据。原型在页面内保留两份示例的临时操作状态；刷新恢复初始值。正式实现复用现有本体切换及保存协调逻辑，不能将原型内存快照替代真实保存；异步响应仍需校验本体 ID 与请求代次。
