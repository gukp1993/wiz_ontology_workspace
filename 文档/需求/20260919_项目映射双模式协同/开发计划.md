## 1. 现状入口

- frontend/src/project/ObjectSources.vue：对象实例身份与来源配置。
- frontend/src/project/PropertySources.vue：属性来源清单、单页表单、编排输入输出绑定。
- frontend/src/project/bindingModel.ts：新旧来源读取与提交，当前 PropertyView 不包含自然语言组合语义。
- frontend/src/project/api.ts、frontend/src/app/http.ts、saveCoordinator.ts：请求与保存边界，复用不重写。
- workbench/project_validation.py 及其分模块：类型、引用、身份校验；规则变更同步金样。
- workbench/project_property_reader.py：现有预览支持范围有限，不能把已有编排绑定当作所有来源已打通执行。
- workbench/storage/：在线 SQLite 权威存储；不得回退到手改 YAML。

实施前重新核对这些入口与接口文档，以免并行开发后信息过时。

## 2. 实施阶段（仅供后续授权）

### A. 交互确认与协议冻结

确认两区域并列、配置方式自动派生、冲突反馈。按接口文档先确定对象说明与属性说明存放位置、连接/上下文稳定引用、组合包装格式及版本。建议在项目映射层扩展，不能在本体属性增加物理来源字段。

需冻结：纯自然语言实例身份、说明保存与发布条件、不支持客户端处理、结构化结果与最终属性类型、模型失败/歧义/冲突状态。现阶段不在原型中伪造最终 API 字段。

### B. 配置和持久化

先后端支持保存/读取/版本快照/兼容校验，再前端接入两区域。旧来源原样兼容，不能旧客户端保存一次就丢说明。unknown 分支零丢失，展示不支持时不可编辑覆盖。说明有变动时使检查结果失效。

阶段 B 只能声明“配置已保存”，不能宣称自然语言已参与实际取值。

### C. 解释与只读取值执行

显式增加解释/执行接口，复用现有模型配置和安全凭据管理。结构化取值先执行，说明与上下文交给解释层，连接凭据只在服务端使用。工具调用执行实际查询/计算；失败和冲突均返回具体原因。限制循环引用、步骤数、结果量与时间；最终结果按属性类型检查。

先完成额定功率直取、实时 SOC 组合、动态采样定位三条链路，另做纯自然语言对象来源身份解析测试。暂不扩展动作执行与任意 Python 沙箱。

### D. 回归与交付

旧映射读写回环、纯描述与组合的持久化/发布、409、连接权限、引用改名/删除、结果类型、模型错误和执行边界。前端 build + 隔离服务浏览器验收，真实数据根/数据库连接不能用于写入测试。性能只测必要链路，不为原型任务跑全系统回归。

## 3. 并行边界

协议冻结前不要并行改前后端数据结构。冻结后可按对象配置、属性配置、后端解释执行分工，共享 bindingModel、协议文件与保存协调器单人负责。只读调研可并行；不要求特定 harness 或代理数量。
