## 1. 可以保留的实现

| 当前实现 | 审阅意见 |
|---|---|
| 页头只保留“测试编排”，范围在测试页选择 | 合理，入口更清楚。不要恢复“测试片段”“打开测试调试”等重复主入口 |
| 节点详情保留“测试此节点” | 是有明确目标的快捷入口，可保留 |
| 整条、连续片段、单节点合并在一个范围下拉 | 当前规模下可以接受，不强制改回多个选择器 |
| 独立测试页：左输入、右结果；设计页不继续向下堆测试结果 | 方向正确，1440×900 实际页面有足够结果空间 |
| 标量突出显示，同时提供 JSON；节点结果分别切换 | 可保留；需要补齐列表等非标量类型 |
| 连续节点配置区、画布及紧凑问题栏 | 保留现有布局，不为原型色彩、间距或控件实现差异重构 |
| 输入来源仍采用现有分层选择 | 本轮不强制改成原型的一体化分组选择器；引用准确、兼容性提示与已有字段能力不能退化 |

实际验证：五节点链 A=x、B=x+2、C=x×3、D=x÷2、E=x×100，只测试 B–C–D，给 B 输入 8，得到 10、30、15，结果仅出现 B/C/D。核心片段执行能力已具备。

## 3. 修正要求

### R01 运行生命周期

- 同一测试工作区一次只允许一个待确认/执行中的提交；同步校验通过后、第一次异步确认之前占用状态，防连点和键盘重复提交。
- 确认、实际请求、界面快照必须基于同一份克隆配置、项目、范围与输入。不能确认旧范围却提交新范围。
- 待确认与运行中禁用再次执行；取消确认、成功、请求失败均正确释放。返回设计再进入仍显示该请求状态，不能绕开限制。
- 旧响应不能覆盖另一个编排、项目、账号的当前结果；可以丢弃已经离开的上下文响应，不要求新增运行历史或后台取消。
- 保留全图现有 revision/CAS 和 per-flow 互斥。前端去重不等于跨客户端幂等，本期不新增通用幂等平台。

### R02 范围选择与校验

- 用明确的选择模式控制多路径复选区，不用 selected.length 代替模式。勾选、取消、空选、修正选择时列表保持可操作。
- 明确显示当前集合与依赖执行顺序；选择 B+D 缺 C 必须提示不连通，不替用户补选节点。
- 全图按现有合法 DAG 语义执行，允许多个独立处理分支；片段仍按既有连续/连通要求校验。不要通过取消所有模式的连通检查来修全图。
- 所有模式的禁用原因在按钮附近可见；选了空/失效节点要说明原因。

### R03 一套测试输入表单

- 每个入口稳定 ID 只渲染一次。全图展示入口声明，单节点/片段只展示需要的入口；同一入口被多个节点引用也只填一次。
- 统一采用已有类型控件：布尔下拉；对象/列表 JSON 输入及校验；数值输入；文本输入。所有模式一致。
- 明确区分“未提供”与“显式空文本”：文本支持“使用空文本”或等价明确操作。0、false、空文本均可作为合法值；非法布尔文本不能静默变 false。
- 输入存在性与类型值分开维护；不新增 nullable 类型体系，不擅自全局改变旧接口允许 null 的兼容语义。新界面对需要填写的值不可把未填写静默转 null。
- 后端仍是权威校验；界面显示可定位的字段错误。内部输入/固定值不能因表单变化变成可覆盖。

### R04 范围保留与结果归属

- 第一次点击主入口默认整条；之后主入口恢复当前编排、项目的上次范围和输入。节点快捷入口才显式改为该节点。
- 返回设计再进入测试，保留范围、显式选集、输入和结果。范围选项本身变化时，不自动运行。
- 结果标题、项目名、节点名、输出声明等来自提交快照；当前表单信息单独展示。修改名称、删除节点或切换项目不会改写旧结果标题。
- 输入缓存按编排/项目/输入稳定 ID/声明签名隔离；不同项目默认不复用测试值；声明改型或删除时让对应缓存失效，不能同名错配。
- 项目/配置变化、范围/输入变化按原需求标明“旧项目/旧配置结果”或“尚未按当前范围和输入运行”。允许清除跨项目结果并提示，不强制保存多套结果记录。

### R05 结果类型呈现

| 实际输出 | 展示方式 |
|---|---|
| 数值、文本、布尔、null | 保留标量与 JSON；false/0 不显示为空 |
| 对象 | 格式化 JSON，长内容在结果区滚动 |
| 对象列表 | 表格预览，列来自实际字段；嵌套值可用 JSON；原始 JSON 可切换 |
| 数值/文本/布尔列表 | “序号 / 值”表格或完整 JSON，不能空白 |
| 混合/嵌套列表 | 优先 JSON，不强凑对象表格 |
| 空列表 | “空列表（0 项）”且可看 []，不等同没有输出 |

表格最多预览 100 行并提示，不影响下游真实数据。不要每个单元格重复扫描整个数组生成列。

### R06 真正有界的输入预览

- 保持现有 inputs + inputsTruncated 响应字段；只有展示副本截断，执行器收到完整原值。
- 返回的 inputs 经 UTF-8 JSON 序列化后不超过 **64KiB**（含字段名、标记及结构开销），每个列表最多展示 100 项。
- 大字符串、嵌套对象、嵌套列表、中文、超长字段名、多输入合计均计入预算；预算不足时用简短合法 JSON 标记/省略，禁止只置标志而返回完整值。
- 正常大小的值保持原结构；截断值允许以明确预览标记代替，绝不声称仍是完整可计算数据。具体兼容格式先登记接口文档。
- 此预算只针对输入预览，不擅自改变既有节点输出协议或执行值上限。保留已有凭据保护。

## 4. 范围边界

不重新设计整套画布、不新增节点/循环/调度/历史、不引入 Python 沙箱、不修改属性取值规则和本体格式、不迁移真实数据、不扩展列表公式语言。不要求为了视觉差异改回旧原型。原型仅演示本次修正路径，正式功能继续走现有接口与真实执行器。
