## 3. 必须覆盖的验收用例

| ID | 验收动作 | 通过标准 |
|---|---|---|
| A01 | 延迟请求中连续点击运行；异步确认未完成时连点 | 至多1个确认流程、1个run请求；按钮显示等待；取消/失败后能再运行 |
| A02 | 运行时返回设计再进入；切项目后旧请求回包 | 不能绕过当前请求等待态；响应不标为新项目结果、不串账号 |
| A03 | A→B→D / A→C→D，勾B再勾D再取消B | 始终可继续选择；当前集合和诊断明确；不会首次勾选即消失 |
| A04 | 独立A/B均从入口读取，整条测试 | 通过现有配置校验后可执行全部节点；片段B+D缺C仍拒绝 |
| A05 | A→B→C→D→E，只测B–D，B输入8 | 输出10/30/15；执行器调用A/E次数严格为0；非靠结果列表推测 |
| A06 | 整条、单节点、片段共用入口 | 稳定ID只渲染一次；bool用下拉；JSON有结构校验；错误有字段定位 |
| A07 | 0、false、显式空文本、未提供、非法布尔 | 前三者按类型合法；未提供明确处理；非法布尔不转false；旧接口兼容未被暗改 |
| A08 | B–D→返回设计→主入口；节点快捷入口 | 主入口保留B–D、输入和结果；快捷入口才切到指定节点 |
