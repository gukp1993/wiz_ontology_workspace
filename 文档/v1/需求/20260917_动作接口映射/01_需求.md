# 动作接口映射一期需求

日期：2026-09-17。范围：HTTP 接口配置、存储、结构校验。没有真实 HTTP 调用或设备控制。

交互依据：[动作接口映射原型 V1](../../prototypes/动作接口映射交互原型_v1.html)。本文件补充原型未覆盖的旧数据兼容和真实数据来源；不要把原型示例当真实资源。

## 1. 入口与边界

复用项目映射 → 对象映射 → 动作绑定页签（现已存在），不新建重复菜单。动作及对象关联只取当前项目固定引用的已发布本体版本 refState；不能取最新本体草稿。

一个项目内，一组对象类型＋动作只配置一个有效实现。保存进入项目 bindings.actionBindings，随项目草稿/项目版本发布，本体定义不受影响。

一期新建实现仅支持 HTTP 接口，不提供函数编排选择、执行、连通性测试或下发指令。已有 flow 绑定兼容只读保留，不擅自转换或删除。

## 2. 列表和编辑

列表三列：动作名称、接口地址、操作。未配置显示“尚未配置”，操作“配置接口”；已配置显示方式和地址，操作“修改接口”。历史 flow 或失效关联保留原有只读查看/明确移除能力，不新增状态列。

配置使用单个弹窗，名称/业务定义只读；按顺序展示基本信息、请求参数、折叠认证配置、请求示意。保存与取消在底部，关闭/Esc/离开有脏表单保护。不要增加多步骤向导或其他页签。

### 基本信息

| 字段 | 必填 | 控件/约束 |
|---|---|---|
| 本体动作、业务定义 | 自动带出 | 只读，不复制成可编辑本体数据 |
| 请求方式 | 是 | AppSelect：GET/POST/PUT/PATCH/DELETE；新建默认POST |
| 接口地址 | 是 | 完整http(s) URL，允许路径参数如 `/devices/{deviceId}/stop` |
| 请求体格式 | 存在请求体参数时 | JSON或表单；表单指application/x-www-form-urlencoded；默认JSON |
| 接口说明 | 否 | 文本，描述用途和返回含义 |

一期没有项目API主机配置，故新配置填写完整地址，不接受缺少主机的相对地址。历史相对path保持兼容，显式编辑成新格式时再要求补齐。地址不含账号密码、密钥或认证查询值，认证通过凭据引用维护。

### 参数表

可新增/移除任意行，零参数合法。每行字段如下：

| 字段 | 要求 |
|---|---|
| 参数名 | 必填；路径、Query、请求头或请求体中的名称 |
| 参数位置 | 路径、Query、请求头、请求体 |
| 取值来源 | 动作输入、当前对象实例主键、当前对象属性、固定值 |
| 来源项/固定值 | 按取值来源联动；实例主键自动确定，其余选择或填写 |
| 值类型 | 固定值可选文本/数值/是或否；其他继承可得来源类型，只读 |

来源必须真实：
- 动作输入只来自引用版本中该动作真实已有的inputs。当前definitionVersion=2动作仅三个业务字段，没有inputs；此时“动作输入”禁用并说明原因，不伪造选项，不修改本体动作表单。
- 实例主键来自当前对象项目身份配置，可为数字或文本。目录类型未知时显示“按实际主键类型”，不可写死数值。缺少身份配置时提示先完成实例识别；不强制要求虚拟登记对象绑定数据库表。
- 当前对象属性：从引用版本的对象有效属性中，筛选已配置可用来源的普通标量属性；时间序列不能直接作为本期标量参数。缺少映射/类型不支持时显示原因。稳定属性ID存储，不用显示名。
- 固定值明确保留JSON数值/布尔类型；0、false有效，文本空串可以是显式固定值。

一期请求体仅一层键值，不做嵌套JSON编辑器、数组、文件、multipart或原始代码。对象/结构类型动作输入不直接传参；显示不支持，改选实例主键或属性。请求头/Query/路径按HTTP文本序列化，JSON请求体保留值类型。

## 3. 认证（选填，默认折叠）

| 字段 | 规则 |
|---|---|
| 认证方式 | 无认证（默认）、Bearer Token、API Key |
| 凭据引用 | 非无认证时必填，只列当前项目API凭据 |
| 参数位置、参数名 | API Key时配置：请求头或Query，例如X-API-Key |

现有 secrets.py 是数据库连接凭据实现，不可列举其密码当作API凭据。先检查是否已有独立API凭据支持；没有则做最小的项目级API凭据引用支持：在此配置区提供“登记凭据”的小弹窗（名称＋掩码密钥），独立命名空间写入受保护vault，返回id/name而不返回密钥。不建全站接口库或新凭据管理菜单。

项目快照仅存凭据ID，密钥不进 bindings、原型、日志或导出。已有数据库/Redis凭据和接口不得改变。没有可用凭据时显示真实空态，不可放入假下拉项；无认证仍可正常配置。

保存示意中只显示“受保护凭据”，包括API Key Query场景；URL中不渲染真实值。凭据保存复用项目本地安全边界，新的API凭据端点仍须Origin/大小/路由白名单，禁止明文回显。认证方式切换时不得自动删除vault中的凭据。

## 4. 请求示意与保存

请求示意始终是文本：方式、地址、请求头、请求体。参数以业务占位符显示，不查询设备/属性真实值。JSON中数字与布尔值保留类型。路径/Query/表单中的已知固定值正确编码，未知变量保留易读占位符。Content-Type随格式生成，认证不泄露。

编辑过程中联动更新，可保留原型“更新示意”按钮。不能调用外部URL，不能验证设备是否停止，不能调用函数或Redis取实际值。

示例“停止充放电”：POST `https://ems.example.com/api/storage/stop`；JSON中deviceId来自当前对象主键，power固定数值0。该地址是示例，不自动填入真实项目。“填入示例”仅原型保留，正式页面不增加快捷灌入示例功能。

点击保存先做配置检查，然后经既有项目form-save/Saver一次持久化；失败留在弹窗保留输入。取消不写入草稿。刷新仍可回显，项目版本引用不改变。本期没有返回结果映射、成功判定、重试或超时配置。

## 5. 校验要求

前后端规则一致，错误须有动作名称与参数位置，不能只输出技术ID。

- 新版本绑定校验方式白名单、http(s)完整地址和必要字段；URL禁止userinfo，fragment不参与HTTP请求应提示移除。
- 路径占位符与path参数一一对应；新建不支持主机名动态模板。
- 相同位置参数名唯一，请求头名称不区分大小写；URL已有Query与参数表重名时提示用户统一维护。
- 参数来源必需引用有效；实例主键绑定须有可用身份定义；固定数值/布尔有效。
- GET不允许请求体参数；切换方式不静默清除已有参数，提示用户处理。
- JSON/表单类型与Content-Type冲突时提示修正，不能重复生成不同Content-Type。
- 认证凭据类型/项目范围正确；Authorization与Bearer重复、API Key与同位置同名参数重复须提示。
- 动作、对象、关联和属性引用失效保留原配置，阻止其发布并提示定位修复，不能自动删除。
- 未为某动作配置接口不是全项目发布阻断条件；已配置的无效绑定才阻断。
- 本次仅配置校验，通过不代表接口可用或动作可执行。

## 6. 兼容与不做

旧api绑定仅有path/roles/paramNotes；旧flow绑定有flowId：均无损读取和保存。不得从paramNotes猜参数名/来源，不将旧path自动升级为完整HTTP配置。已发布快照不可改写；未知实现kind只读保留。

不新增本体字段、不改业务规则库、不扩展函数编排、不建接口注册中心、不引入后台执行器、不发测试请求、不自动迁移真实数据、不重构属性来源或身份配置。
