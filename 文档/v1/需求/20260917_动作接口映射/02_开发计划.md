## 2. 固定协议

沿用 `bindings.actionBindings[]` 的 id/objectTypeId/actionId，扩展implementation，不换文件。建议新版本采用：

```json
{
  "id": "绑定稳定ID",
  "objectTypeId": "沿用现有对象ID规范",
  "actionId": "现有动作ID",
  "implementation": {
    "kind": "api",
    "schemaVersion": 2,
    "method": "POST",
    "path": "https://ems.example.com/api/storage/stop",
    "bodyFormat": "json",
    "description": "停止充放电请求",
    "parameters": [
      {
        "id": "参数行稳定ID",
        "name": "deviceId",
        "in": "body",
        "value": {"from": "instanceId"}
      },
      {
        "id": "参数行稳定ID",
        "name": "power",
        "in": "body",
        "value": {"from": "constant", "type": "number", "value": 0}
      }
    ],
    "auth": {"type": "none"}
  }
}
```

来源扩展：`{from:'actionInput', inputId:'真实输入稳定标识'}`、`{from:'property', propertyId:'稳定属性ID'}`。历史输入缺少稳定ID时只兼容已有非空唯一参数名并显式编码inputName，不凭空生成跨版本ID；歧义条目不允许新选。不在本体补inputs。

位置：path/query/header/body；格式：json/form；固定值类型：string/number/boolean。非固定值继承真实来源，不重复缓存主键类型。

认证：`{type:'bearer',credentialId:'...'}` 或 `{type:'apiKey',credentialId:'...',in:'header',name:'X-API-Key'}`。凭据元数据属于当前项目受保护凭据域，由服务读取名称列表，不把秘密字段放进项目配置。

规则：无schemaVersion的api是旧格式，维持旧校验。版本2才应用本期完整校验。旧数据转新格式必须由用户显式保存完成，不静默补假默认值。旧roles/paramNotes及未知字段保存时保留，不在新表单增加编辑项；旧flow保持只读。

## 3. 实施分解

### P0：核对与锁定协议

读取当前AGENTS及需求/原型；检查现有保存、凭据和动作引用实现。列出实际要修改的文件，确认schemaVersion是否冲突；若已有版本2，保持等价语义并先记录差异，不覆盖已使用字段。

### P1：纯数据和校验

实现读取、旧/新格式识别、参数来源、去重校验、请求示意生成。先以几条隔离样例验证数字0、布尔false、中文Query编码、未知类型和旧字段不丢失。

### P2：单页弹窗

在ActionBindings上实现原型的HTTP配置；沿用AppSelect和现有表单保存机制。来源下拉与取值控件联动，固定值类型正确；Body和认证按条件展示。不新增运行按钮。对象/版本切换不能覆盖未保存填写。

### P3：凭据引用

确认是否已有项目API凭据；没有则补最小登记、列举元数据能力。项目ID校验、vault权限0600、原子写入、不返回密钥；只读请求示意不会读取密钥。数据库/Redis探测路径不变。不引入通用接口平台。

### P4：项目存储与发布接入

扩展项目校验与问题定位；复用现有绑定保存/发布/引用升级预检。更新项目校验金样，仅新增预期用例，不重写旧用例结果。无效旧引用保留，禁止发布但允许修复草稿。

### P5：定向验证与交付

使用临时数据根与独立端口。相关测试通过后构建前端并浏览器核验；不要重复跑无关算法/网络集成，也不要仅凭build宣布完成。

## 4. 验收清单

| 编号 | 场景 | 通过标准 |
|---|---|---|
| H01 | 对象动作列表 | 只来自项目引用版本；本体草稿变化不影响当前列表 |
| H02 | 配置/编辑/刷新 | 一次保存持久化，字段和值类型完整回显 |
| H03 | 参数联动 | 四类来源基于真实定义；新版无inputs时清楚禁用该来源 |
| H04 | 主键与属性 | 字符串主键不转数值；稳定属性引用改名不丢失 |
| H05 | 请求示意 | 路径替换、Query编码、JSON的0/false、表单编码正确，无取数/请求 |
| H06 | 认证 | 仅本项目API凭据，列表无明文；保存与快照无密钥；示意脱敏 |
| H07 | 配置错误 | 缺地址/错占位符/重复参数/错数值/GET body/认证冲突可定位 |
| H08 | 保存失败/取消/Esc | 不假成功，不丢输入或污染已保存配置；遵守现有并发保护 |
| H09 | 历史api/flow/未知字段 | 不丢失、不自动迁移，旧flow只读保留 |
| H10 | 升级引用 | 动作或关联失效仍可查看，配置保留并明确提示 |
| H11 | 发布边界 | 未配置动作不强制阻断；配置错误阻断；只改项目不改本体 |
| H12 | 安全边界 | 无真实HTTP调用；新增凭据端点沿用Origin/路由/大小保护 |

运行要求：新增少量针对性纯测试和临时目录roundtrip；修改项目校验必须运行金样回归；`cd frontend && npm run build`。真实业务数据不作自动化试验。

交付：变更文件、实际测试结果、浏览器交互核验、凭据处理方式、兼容说明及未完成项。不能把原型假数据当作通过证据。
