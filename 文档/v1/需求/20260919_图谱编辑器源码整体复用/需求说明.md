## 3. 数据与操作适配

### 3.1 图谱数据

工作台本体草稿仍是唯一业务数据来源。旧编辑器的 nodes/edges 是显示与编辑会话模型，不另建永久草稿库。禁止把整个画布图反向覆盖本体，只能提交明确的领域操作。

| 图元素 | 当前领域含义 | 关键约束 |
|---|---|---|
| 对象节点 | 对象类型定义 | ID 由现有流程生成；显示名不作主键 |
| 共享属性节点 | 共享属性定义 | 多对象引用同一节点；修改前提示引用影响 |
| 私有属性节点 | 对象拥有的属性定义 | 身份含所属对象，不因同名合并；新建须选择所属对象 |
| 规则、动作节点 | 业务规则/动作定义 | 保留当前结构化字段和扩展字段；不是运行实例 |
| 对象→对象边 | 链接定义 | 保留名称、反向名称、基数等当前字段；支持自环、平行边 |
| 对象→共享属性/规则/动作边 | 关联引用 | 删除边仅解除引用，不删除库定义 |
| 对象→私有属性边 | 所属关系 | 不是可随意断开的普通引用；移除需走删除私有属性确认 |

图节点 ID 使用“类型+领域 ID”，私有属性附所属对象 ID；边使用稳定链接 ID 或“关系类型+端点稳定 ID+引用身份”，不以名称去重。详情导航携带元素类型与身份，链接返回按边定位。多本体预览再附本体与版本身份。

属性包含时间序列及观测值类型等当前所有定义；不得以旧字段表覆盖，丢失 extensions、definitionOrder、共享引用、显示名称等字段。旧编辑器原有实体/属性/规则类型表扩展为当前五类，颜色/图标/布局分组同步扩展。

### 3.2 编辑命令

- 新建节点选择领域类型；私有属性先选所属对象，默认当前选中对象。复用旧弹窗布局，字段与当前建模表单一致，优先共享字段组件/校验逻辑。
- 对象→对象进入当前链接字段确认；对象→共享属性/规则/动作建立引用；重复引用提示“已关联”，不重复创建。
- 私有属性不直接拖连到另一个对象以改变归属；提示当前不支持改变所属对象。其他不支持的端点组合给明确原因，不存通用关系逃避业务校验。
- 批量连线先校验全部目标并展示结果，一次确认、一次业务变更；有失败时不静默部分成功。
- 编辑共享定义显示引用范围；删除共享属性/规则/动作时展示引用影响，默认阻止仍有引用的定义删除并提供处理入口，不静默清空引用。对象删除沿用当前对象删除约束。
- 撤销/重做针对本编辑会话的领域操作恢复实际模型；不能只让 Cytoscape 图形回退而列表/数据库不变。外部编辑、切换本体/版本后重建基线，旧撤销栈不可覆盖新状态。
- 业务编辑经现有 before-change/changed、保存协调器、revision 和接口保存。失败保留可恢复的编辑内容并显示错误；不得假报成功。409 沿用当前冲突策略，不直接覆盖服务端。

### 3.3 视图状态

坐标、视口、面板、筛选与选中属于视图；按账号/本体/版本隔离，复用当前偏好封装。不得因拖动、搜索、布局、预览、坐标导入改变本体发布版本或产生业务保存请求。

邻域布局是临时坐标层；全图坐标与视口单独保留。返回全图、换中心、切页、刷新、卸载后均可正确恢复，不把环形临时位置写为基础位置。业务撤销与布局撤销各自明确，快捷键只派发一次。

## 4. 架构与代码复用要求

建议将旧编辑器整套前端模块放在 `frontend/src/ontology/legacyGraph/`（名称可按仓库调整），复制 `EditorView.vue` 为主组件、相关弹窗、shared、预览页、布局/多图工具及所需依赖。**先保留代码，再改 import 和接入边界；不允许先看源码再重写。** 对旧 useGraph/api/auth/router 的调用提供本地适配或明确改为当前接口。禁止访问旧服务地址，禁止引入第二套登录态、自动保存器、版本库。

适配层职责：读取当前本体并投影；提交领域操作；导航；保存状态；视图偏好；导入导出。它不是新引擎，不承担重写搜索、选择或布局算法。旧模块可保留 JS，补局部类型声明；不得为了移植做全站 TS 重构或全局关闭类型检查。

当前 OntologyGraph 作为薄入口包装或被替换；不得同时保留两套运行的画布事件控制器。现有正确的领域投影可复用，但它只提供数据，不再负责重造旧交互。移除确认无引用的旧控制器代码与调试全局变量，不能留下双实现切换开关作为最终交付。

需要后端新增导出或转换接口时先更新接口文档和白名单，再实施；不复制旧 api.js 指向另一套后端。优先复用现有 API，保持当前 SQLite、账号隔离、不可变发布等边界。
