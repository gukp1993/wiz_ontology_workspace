# 开发计划 · 项目映射说明与配置 v2.1

日期：2026-09-19。当前交付为完整需求与开发任务；正式产品尚未实施。

唯一交互基准：[交互原型_v2.html](交互原型_v2.html)（已简化为单 textarea）。范围和协议：[需求说明.md](需求说明.md)。可交接指令：[执行指令.md](执行指令.md)。v1 仅历史，不参与验收。

## 1. 本次目标与交付边界

实现对象、属性、链接、动作四类项目说明的填写、持久化、读取、版本发布和旧配置兼容；重整对应交互，向后续消费方提供说明与具体配置的完整上下文；在尚不支持说明的实际预览/执行入口增加显式拒绝。

本期不新增 LLM 自主执行、生成 SQL/编排、模型语义审查或设备动作执行。最终报告必须区分“能保存并读取说明”与“能按说明自动取值”。本期不是只做一个无法导出/读取的备注栏。

## 3. 实施任务与完成标准

### T0：锁定基线（主负责人）

- 读取 AGENTS、共享上下文、原型与需求；记录当前 Git 状态和相关测试基线。
- 从原型实际操作四类说明与折叠；不得按旧版截图恢复辅助按钮。
- 核对哪些现有来源允许纯说明而不产生半成品绑定；列出实际预览消费者。

产物：在本文实施记录追加基线、具体文件负责人、既有失败，不另开报告。

### T1：先定文档与共享适配层

- 将需求 §9 的 mappingDescriptions 基线落实到接口文档；若已有同等字段则说明并复用，不重复存储。
- 定义四类稳定 ID、文本上限、缺省/显式清空/旧客户端省略、未知版本、失效引用行为。
- 同步前端类型与后端结构检查的契约；不改本体 modelFormat 协议。
- 设计纯读写辅助函数和“实际配置+说明”的读取结果，不新增聊天或自动执行接口。

完成标准：四类数据结构、保存与发布规则均无待猜测处；前后端按同一接口文档实现。

### T2：后端保存、快照及校验

- 读取/保存整个说明块；JSON 状态沿用现有存储；新字段不意味着新建 SQL 表。
- 在 CAS 检查及写锁内从当前状态补全旧请求省略块，不使用锁外旧状态合并。
- 保存仅校验结构、类型和长度；业务不完整草稿沿用原能力。
- 校验/发布按需求 §10 矩阵：失效引用阻断、纯说明不算可执行配置、已有不完整绑定不放松。
- 升级预检、导出/恢复往返保留说明；历史快照不可修改。

完成标准：D01–D10、D12 的后端部分通过；改校验顺序和文案时更新新增金样，原用例不无故变化。

### T3：前端四类说明和清单

- 可新增一个最小通用说明组件，输入区只有 textarea；标签为“说明”，默认展开且可折叠，提示仅用 placeholder。
- 四页签分别接入；下方具体配置默认折叠、显示已有摘要，展开复用旧表单。
- 清单三列；属性区不增加模式列，动作/链接也不增加机制标识。
- 链接两端共用说明；属性和动作按对象隔离；只读本体定义不允许编辑覆盖。
- 说明和配置走同一次保存，取消及未保存离开保护生效；折叠不写入业务状态。
- 只填说明时不创建空接口、空编排或缺主键的 enabled binding。

完成标准：V01–V09 对照原型通过，D02–D06 前端交互正确；原表单功能不缺失。

### T4：上下文读取与执行边界

- 从现有 state/发布快照/导出可获取目标、原文和具体配置；封装只读上下文辅助函数（必要时复用既有函数）。
- 对本期真实可触发的预览/执行入口，检查目标及其依赖说明。不支持说明时在数据源调用前明确拒绝，不静默执行字段或公式。
- 无说明旧配置保持原行为；动作仍没有发送按钮或测试入口。
- 说明失效依赖不能静默丢弃。旧外部执行器限制记录清楚。

完成标准：D11 通过；mock 驱动/执行器证明阻断发生在调用前。不得把“返回说明字符串”报告为 LLM 执行完成。

### T5：整体验收与交付

- 按 V01–V11、D01–D12 回归；前端类型检查/构建，隔离实例做浏览器实测。
- 四类说明分别检查保存刷新、取消、身份/引用、发布快照和不支持执行提示。
- 更新本文、共享上下文和 Git；只提交本任务内容。

完成标准：可明确报告已完成项、未测项、剩余问题与运行地址；有记录支撑后才使用 verified。
