# 本体区列表统一设计 · v1

日期：2026-09-18
状态：供用户评审及实施的设计基准；本次仅交付方案与原型，正式工作台未按本方案修改。
配套：[交互原型](交互原型_v1.html) · [开发计划](开发计划.md) · [执行指令](执行指令.md)

## 1. 问题与目标

本体区现在混用对象导航行、属性表格、链接卡片、共享属性条目以及动作列表/详情布局。各处行高、工具栏、操作位置和查看方式不一致，用户需要反复学习。

本期统一列表的视觉与交互，采用现有管理后台的深色导航、浅色内容、蓝色主操作风格。不改变本体语义、字段、共享引用、项目映射和持久化协议。

核心决定：**只保留两种列表容器：用于切换上下文的紧凑导航列表，以及用于维护内容的标准数据表格。** 不把所有清单机械改成卡片，也不为“统一”把对象导航做成多列表格。

这是适配当前工作台的设计方案，非声称逐项符合微软或 Palantir 的官方规范。

## 2. 范围：八处列表逐项确定

| 位置 | 列表用途 | 统一容器 | 名称点击后 | 本期主要变化 |
| --- | --- | --- | --- | --- |
| 对象建模 → 左侧对象列表 | 切换当前对象 | 紧凑导航列表 | 更新右侧对象详情 | 固定行式样、独立滚动、稳定选中态 |
| 对象建模 → 属性 | 维护对象拥有的属性 | 标准表格 | 只读属性详情 | 统一列、搜索、筛选、分页与操作 |
| 对象建模 → 链接 | 维护与当前对象有关的链接 | 标准表格 | 只读链接详情 | 删除卡片式展示，起点、终点、数量关系分列 |
| 对象建模 → 动作 | 查看对象关联的动作 | 标准表格 | 只读动作详情 | 统一行式样，移除关联收入更多 |
| 对象建模 → 规则 | 查看对象引用的规则 | 标准表格 | 只读规则详情 | 补充已有业务定义摘要，移除引用收入更多 |
| 共享属性菜单 | 维护共享属性定义 | 全宽标准表格 | 只读共享定义详情 | 取消独立条目/卡片风格 |
| 业务规则菜单 | 维护通用业务规则 | 全宽标准表格 | 只读规则详情 | 对齐通用工具栏、表格及操作样式 |
| 动作定义菜单 | 维护通用动作定义 | 全宽标准表格 | 只读动作详情 | 取消左列表/右固定详情布局，改为全宽表格 |

三个资产库保留现有菜单名称，不新增分类页或新的导航层级。

### 本期不做

- 不改变画布、项目区页面、全局设置及发布流程。
- 不调整对象/属性/链接/动作/规则的结构化字段及必填规则。
- 不新增属性类型、对象状态、更新时间、负责人等数据库字段。
- 不增加业务规则删除、批量删除、拖拽排序、列配置或表格/卡片视图切换。
- 不改共享引用为复制，不把对象关联操作变成删除定义。
- 不重做全部编辑表单。已有编辑器、保存取消、表单离开保护、撤销重做继续复用。

## 3. 页面布局

### 3.1 对象建模

```text
应用导航 │ 页面标题：对象建模
         │ ┌对象导航 248px──┬当前对象：名称 / 业务定义 / 原有操作──────┐
         │ │搜索、收藏、排序│属性 | 链接 | 动作 | 规则                │
         │ │对象行         │搜索 / 筛选 / 总数 / 本页操作             │
         │ │…              │标准数据表格                             │
         │ │独立滚动       │分页                                     │
         │ └───────────────┴─────────────────────────────────────────┘
```

对象导航约 248px，窄桌面可为 218px；不得随对象名称长度变化。详情占剩余宽度，表格区域独立滚动。对象总览、列表/画布切换、收藏和对象更多操作等原有能力全部保留；原型为聚焦列表而未展示的入口不代表删除。

### 3.2 三个资产库

```text
应用导航 │ 页面标题：共享属性 / 业务规则 / 动作定义
         │ ┌列表标题 / 一句说明──────────────────────新建───────────┐
         │ │搜索 / 筛选                                  总数      │
         │ │标准数据表格                                           │
         │ │分页                                                   │
         │ └───────────────────────────────────────────────────────┘
```

单个白色内容面板。不再出现资产列表外套一张卡片、每一行再套小卡片的结构。默认展示全部清单；查看时打开右侧只读详情面板，关闭后回到原表格位置。

## 4. 对象导航列表规范

| 项目 | 要求 |
| --- | --- |
| 标题 | 对象类型 + 当前筛选结果数；筛选时可显示“结果 / 总数” |
| 搜索 | 搜索全部对象名称和业务定义，非仅当前可见行 |
| 筛选 | 保留“全部 / 已收藏”两项；使用紧凑分段按钮，不使用不同圆角胶囊风格 |
| 排序 | 名称升序/降序，中文名称排序；保留稳定 ID 作为同名排序的兜底 |
| 每行 | 第一行名称，第二行“属性数 · 链接数”；计数来自现有状态，不新增字段 |
| 行高 | 58px，名称和摘要均单行省略 |
| 选中 | 浅蓝背景 + 左侧 3px 蓝条；不叠加蓝色外框 |
| 悬停 | 浅灰背景；焦点用清晰边框，不能只靠颜色 |
| 点击 | 点击整行选择对象；方向键、Enter 沿用既有键盘导航 |
| 大量数据 | 保留现有分页能力，独立滚动；不得为了固定行数截断真实记录。原型“大量数据”为滚动示意，不替代现有分页 |
| 搜索不中当前对象 | 可以保留右侧当前详情，明确当前选择不在筛选结果中；不得暗中切到另一对象 |

主列表的“新建对象”入口沿用现有位置与事件，不额外新增多个同义按钮。收藏属于视图偏好，沿用既有存储方式。

## 5. 标准表格规范

### 5.1 视觉规则

| 元素 | 统一值/行为 |
| --- | --- |
| 内容背景 | 页面浅灰，列表面板白色 |
| 面板 | 单层 1px 边框、8px 圆角；无重阴影 |
| 内容内边距 | 默认 24px；窄桌面 18px，小屏 12px |
| 表头 | 40px，高度稳定；浅灰背景，中灰文字，13px/600 |
| 表格行 | 最小 64px；垂直内边距 10px；内容两行时自然撑开，不能裁掉文字 |
| 单元格 | 水平内边距 12px；仅横向分隔线，不加纵向网格、不用斑马纹 |
| 主名称 | 13–14px/600，默认深色，悬停变蓝并带下划线；键盘可聚焦 |
| 辅助文字 | 12px，中灰，通常单行省略；完整内容在详情中可见 |
| 正文 | 13–14px；规则、效果摘要最多两行，不在表格内放整段长文 |
| 工具栏控件 | 高度 34px，6px 圆角，间距 8px |
| 主操作 | 每个清单一个蓝色实心按钮；其余为白色边框按钮或行内文本 |
| 选中行 | 只读详情对应行使用浅蓝背景；关闭详情后取消临时高亮 |
| 类型/复用方式 | 中性标签或普通文本；不让每一种类型都有专属颜色 |
| 危险操作 | 更多菜单末尾红色文字，并有具体确认内容 |

建议沿用并统一映射现有 CSS 变量：主文字、次文字、边框、蓝色、浅蓝背景。原型参考值：主文字 #21364B、次文字 #63788E、边框 #DFE6EE、主蓝 #275BEA、浅蓝 #EEF3FF。不要为每个页面重复写颜色。

### 5.2 工具栏和分页

- 左侧：搜索 → 与本清单有关的筛选；右侧：结果数 → 操作按钮。资产库的新建在列表标题行右侧，对象页签的新建/添加在工具栏右侧。
- 名称列支持升降序。搜索匹配名称和业务定义；链接额外匹配两端对象与反向名称。不要求全文搜索整段规则正文。
- 表格默认每页 20 项，分页位于表格底部；搜索或筛选变化返回第一页，排序后页码按合法范围调整。
- 列表少于一页时显示数量，翻页按钮禁用；不因数据少改成卡片布局。
- 切换对象时使用新对象的清单，不残留上一个对象的筛选。返回同一资产库保留搜索、筛选、页码和滚动位置。
- 搜索/排序/分页只影响视图，不调用本体保存接口，不产生撤销记录。
- 不新增每行复选框，直到确有批量操作需求；引用挑选弹窗中的现有多选继续保留。

## 6. 每个表格的列和操作

### 6.1 对象属性

| 列 | 展示内容 | 行为 |
| --- | --- | --- |
| 名称 | 属性有效名称；第二行有效业务定义摘要 | 点击看当前对象属性详情 |
| 数据类型 | 文本/数值/是或否/日期等现有类型；时间序列第二行显示“观测值：数值”等 | 展示已有类型，不新增“结果形态” |
| 复用方式 | “共享引用”或“私有属性”中性标签 | 共享引用可打开共享来源详情；私有仅展示 |
| 操作 | 编辑 + 更多 | 原有编辑器；更多内提供相应删除/移除入口 |

工具栏：名称/定义搜索、复用方式筛选、“从属性库添加”“新建属性”。复用方式筛选值：全部、共享、私有。

共享属性行的名称、定义、类型使用现有 effectiveProperty 语义，不直接读取引用节点的空字段。名称/类型缺失或引用失效时如实提示，不补造数据、不自动转私有。

共享引用在当前对象侧的操作文案为“移除引用”，语义是删除当前对象上的引用记录；私有属性为“删除属性”。两者都不删除共享库的定义。仍执行已有下游引用检查和保存流程。

### 6.2 对象链接

| 列 | 展示内容 |
| --- | --- |
| 链接名称 | 正向名称；第二行“反向：包含储能簇”等，未定义时不强行补名称 |
| 起点对象 | 定义中真实的起点对象名称 |
| 终点对象 | 定义中真实的终点对象名称 |
| 数量关系 | 一对一/一对多/多对一/多对多，沿用现有枚举 |
| 操作 | 编辑 + 更多（删除链接） |

工具栏：搜索、“新建链接”。不新增方向筛选器。

同一链接定义只出现一行；无论当前对象是起点还是终点，都显示定义中真实方向，不交换两端后仍错误沿用原数量关系。自链接也不能重复渲染两行。正反向阅读名称共用一份定义。

删除链接影响两端对象，确认提示必须说明；仍受现有引用保护约束。

### 6.3 对象动作

列：名称（第二行业务定义）｜业务效果（两行摘要）｜操作。

工具栏：搜索、“添加动作”。行操作：查看 + 更多（移除关联）。名称和“查看”都打开同一个只读详情；详情提供“到动作定义维护”，并可返回原对象。

这里管理的是关联，不是创建一份对象私有动作；移除关联只影响当前对象，不删除动作定义、不清理其他对象的关联，项目端旧绑定按原机制提示失效并保留。

### 6.4 对象规则

列：名称｜业务定义（两行摘要）｜操作。

工具栏：搜索、“添加规则”。行操作：查看 + 更多（移除引用）。只读详情显示既有名称、业务定义、规则内容、输出结果，并提供“到业务规则维护”。

移除引用不删除规则正文；本期不新增对象侧编辑规则正文入口。

### 6.5 共享属性库

列：名称（第二行业务定义）｜数据类型｜引用情况｜操作。

- 引用情况显示 N 处引用，按现有 referencesOf 的对象属性引用记录计数，不能把记录数误写成对象类型数。
- 点击引用数打开引用位置，展示对象名称及属性名称，可定位回对象属性行。
- 行操作：编辑 + 更多（引用到对象、复制为私有、删除定义）。名称打开只读共享定义详情。
- 顶部：搜索、数据类型筛选、新建共享属性；粘贴多行、批量复用等既有低频能力集中在页面级“更多操作”。
- 数据类型筛选以现有规范化类型为准，不新增/删减模型枚举；时间序列作为一个筛选项，观测值类型仍在单元格显示。
- **保留现有删除语义**：当前实现删除共享定义会把引用转成完整私有定义，并受外部引用校验限制。不得在 UI 统一过程中悄悄改成级联删属性、无提示断链或一律禁止。确认框说明影响数量、私有化结果及可撤销性。

### 6.6 业务规则库

列：名称｜业务定义（两行摘要）｜引用对象｜操作。

- 引用对象按去重对象类型计数，点击可定位对象规则页签。
- 行操作仅“编辑”，名称承担查看；不重复堆“查看 + 编辑 + 更多”。
- **不显示无内容的更多菜单，不新增删除/复制功能**，与当前业务能力一致。
- 顶部：名称/定义搜索、引用情况筛选（全部、有引用、无引用）、新建规则。
- 规则编辑继续是已有四字段，不在列表增加要求用户填写的新字段。

### 6.7 动作定义库

列：名称（第二行业务定义）｜业务效果｜关联对象｜操作。

- 关联对象按去重对象类型计数，点击可定位对象动作页签。
- 行操作：编辑 + 更多（删除定义）；被引用的动作继续受现有删除保护限制。
- 顶部：名称/定义搜索、引用情况筛选、新建动作。
- 历史格式保留只读标记和既有“转为新格式编辑”入口，不因统一表格自动转换或丢弃历史字段。
- 不恢复此前移除的动作输入参数、提交条件等表单项。

## 7. 统一详情及返回路径

列表名点击、行内查看统一打开右侧只读详情面板，宽约 480px；关闭按钮、Esc、点击遮罩均可关闭。详情不自动保存任何内容。

- 列表原位置与条件保留；面板关闭后焦点回到触发元素，若该行已不存在则回到搜索框。
- 面板标题为记录名称，按业务字段顺序展示完整定义；引用位置提供可点击对象入口。
- 点击“编辑”继续进入该模块原有编辑器，不要求把所有编辑表单迁入抽屉。
- 跨菜单查看共享定义/动作/规则时保存来源对象与页签信息，提供返回来源；返回后恢复定位。
- 有未保存表单时切换对象、菜单、详情或离开，继续走现有 formGuard；不能以只读面板为由绕开守卫。
- 详情里只读正文不是可执行指令，不执行任何项目动作或函数。

## 8. 状态与可访问性

| 状态 | 展示及行为 |
| --- | --- |
| 初始无数据 | 中性空状态 + 一句说明，使用工具栏中的唯一主入口，不在空态重复新建按钮 |
| 搜索无结果 | “没有匹配的…” + 清空筛选；不得引导用户重复创建已有记录 |
| 加载中 | 沿用页面真实请求状态，使用同尺寸占位或已有加载提示；不制造额外请求 |
| 加载失败 | 可读错误和重试；不能把失败当成空列表，不清空已有内存状态 |
| 引用失效 | 行保留并标明定义不存在；禁止打开虚构编辑器；仍提供原有移除路径 |
| 历史格式 | 使用中性“历史格式”标记，保留兼容入口 |
| 正在保存/保存失败 | 沿用现有保存状态，失败保留表单；不以关闭弹窗假装成功 |

所有按钮、名称链接和菜单键盘可用；菜单支持方向键与 Esc，详情面板有焦点约束与焦点归还。省略文字不能只依赖鼠标 title：名称/查看入口可读完整内容。颜色之外保留文本说明。

表头使用语义 table/th，名称排序设置 aria-sort；对象当前行设置 aria-current，页签设置 aria-selected。没有批量选择功能时不把普通表格伪装为可多选 grid。

## 9. 窄屏与大数据

- 页面可用宽度不足约 900px 时，对象导航/详情采用既有单栏切换方式，详情有“返回对象列表”。不得挤压成不可读的三栏。
- 表格设置合理最小宽度，列不足时在表格区域横向滚动，不让整页横向溢出；不在窄屏自动换成第三种卡片样式。
- 详情面板不超过视口宽度；小屏占满内容宽度。
- 搜索和排序基于完整列表，再分页；缺省每页 20 项，切页不丢搜索条件。
- 本期不引入虚拟滚动库、后端分页 API 或新状态库；若真实规模导致性能问题，先测量再立项。

## 10. 实现约束与真实数据保护

本需求仅 UI 展示和导航调整，不新增接口、数据库表或模型字段。类型展示、引用计数、名称/摘要从现有数据派生。

复用 AppSelect、RowMenu、appConfirm、PropertyManager、BusinessRuleDialog、formGuard、form-save 等现有能力。共享样式限于本体列表，不修改全站 table/button 选择器而误伤项目映射和编排页面。

只读浏览不保存；写操作仍用稳定 ID、现有 before-change/changed/form-save 流程。保存失败、409 冲突、旧格式、未知字段、撤销重做保护不得退化。禁止为“演示统一列表”改写真实本体草稿或用户数据库。

## 11. 验收清单

| 编号 | 标准 |

## 12. 原型覆盖与差异

原型可体验四个菜单、四个对象页签、导航搜索/收藏/排序、表格搜索/筛选/排序/分页、只读详情、引用跳转、更多菜单、部分对象关联添加/移除、空/失败/大量数据场景。

原型使用内存示例，不联网、不读写真实数据；刷新恢复。新建/编辑、共享删除私有化和链接删除引用校验属于原有业务流程，原型只显示入口说明，不冒充已实现。正式版须接回已有能力，不能复制说明占位作为正式功能。

原型未展示的对象画布、新建本体、批量工具完整表单等现有功能仍须保留。表格/导航采用本规范；保存、兼容、引用与数据安全以正式需求和既有系统约束为准。
