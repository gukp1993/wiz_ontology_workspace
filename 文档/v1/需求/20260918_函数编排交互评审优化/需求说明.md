# 函数编排编辑页：最终交互优化方案

版本：v1 · 2026-09-18 · 状态：方案交付，尚未修改正式工作台。

本轮四件套：[交互原型](交互原型_v1.html) · [开发计划](开发计划.md) · [执行指令](执行指令.md)。

## 1. 结论与范围

保留现有函数编排模型和执行能力，改成“画布为中心、选中才展开配置、检查问题直接定位、测试入口按范围区分”的编辑器。不是重新设计执行平台。

用户的主要任务仍是：添加节点 → 配置输入、实现和输出 → 建立参数绑定 → 检查配置 → 测试一个节点、一组节点或完整编排。

本期保留 SQL、Python、计算、Redis、HTTP 五种节点，以及现有稳定 ID、输入绑定、编排输入/输出、保存与撤销重做。连线继续由参数绑定派生，不能另外存一套边关系。

不新增：执行引擎、Python 沙箱、调度、版本历史页、运行历史库、流式日志、子流程、循环节点、自动调参、AI 自动修复、数据库结构管理。不得把 Python 的 LLM 推演展示成真实 Python 执行。编排仍是独立资产；外部连接与凭据按现有项目上下文解析。

## 3. 页面布局

### 3.1 信息分区

```text
[收起的全局导航]  返回编排列表 / 编排名称         保存状态  检查配置  运行全部
                说明（默认收起） / 当前项目上下文
                节点列表  添加节点  建立绑定  选择测试节点     整理  全图  100%
                模式提示：当前操作、已选范围、退出方式（占位高度固定）
                ┌ 可收起列表 ┬         画布          ┬ 按需显示的节点详情 ┐
                │ 名称/类型  │  节点、绑定、问题标记   │ 名称  测试此节点 ⋯ │
                │ 问题数量   │                       │ 输入/实现/输出/高级│
                └───────────┴───────────────────────┴───────────────────┘
                问题 / 本次结果（按需展开；不依附任何节点详情）
```

顶部只把“运行全部”设为实心主按钮。“检查配置”是次按钮，问题数量可点击。保存继续使用现有协调器与状态条，不新增保存草稿步骤。

### 3.2 尺寸与响应式规则

| 视口 | 节点列表 | 详情 | 画布与高度 |
|---|---|---|---|
| ≥1440 px | 180 px，可收起 | 选中后 400 px；无选中不占宽 | 尽量留下 ≥640 px；页面 flex 占剩余高度 |
| 1100–1439 px | 默认抽屉，可手动展开；挤压画布时回抽屉 | 360–400 px | 画布目标 ≥560 px；1366×768 无整页纵向溢出 |
| 768–1099 px | 抽屉 | 右侧覆盖式面板，可关闭 | 不把详情堆到画布下面 |
| <768 px | 抽屉 | 全屏详情返回画布 | 控件分组换行，不缩小到不可点 |

尺寸是实现目标，以实际可用宽度再退化；禁止为保持三栏导致整页横向滚动。详情可拖动宽度 360–560 px，但不能挤掉画布；不满足条件就使用覆盖面板。小屏不提供拖拽宽度。

编辑器容器使用剩余空间布局、`min-height:0`；画布、列表、详情分别管理滚动。去掉 `calc(100vh - 320px)` + `min-height:480px` 的叠加依赖。编辑器专注布局只作用于 f-editor，离开后恢复全局导航习惯，不重构其他页面。

问题/结果面板默认 200 px、可收起，桌面最高不超过工作区约 35%；可用高度不足时改覆盖面板，不把画布压到不可用。工具栏有独立行，不能浮在节点上。

### 3.3 画布视口

- 初次打开使用可读的初始布局；已保存视口有效时可恢复，视口完全偏离内容才提供“返回内容”。小图可初次 fit，大图优先正常倍率并显示“全图”入口。
- 点击列表、定位问题时聚焦目标节点；保持足够可读倍率。
- 打开详情、选择测试范围、结果返回、检查状态变化，不自动全图缩放。
- “全图”是用户明确要求看全貌；“100%”恢复可读倍率；不要承诺任意大图在全图状态仍可阅读全部文字。
- “整理”改变节点位置，可撤销；缩放/平移不触发业务保存。仅更新状态的操作不要销毁再添加全部图元素。

## 4. 节点配置

详情头部：节点类型、名称、测试此节点、更多操作、关闭。更多操作收纳删除和覆盖型操作。边界节点展示编排输入/输出，不出现不能使用的单节点测试按钮。

| 页签 | 主要内容 | 简化方式 |
|---|---|---|
| 输入 | 参数名、类型、取值来源、绑定 | 每个参数一行摘要，展开后配置；来源选择后只展示相关字段 |
| 实现 | SQL / Python / 计算公式 / Redis / HTTP 对应编辑器 | 只显示当前种类；默认进入此页签，问题定位可切换 |
| 输出 | 输出参数名、类型与现有输出映射 | 复用当前类型组件；不能虚构执行器不支持的推导 |
| 高级 | 执行超时、行数上限、其他现有高级项 | 默认不展开；已开启写入等重要状态在实现页摘要提示 |

参数名用于代码引用，不能删掉或改成纯中文标签。显示名、说明等非必填内容放在展开区；对象/数组类型结构按现有能力维护。固定值和来源绑定遵循现有协议，不另设重复字段。

代码区：等宽字体、独立滚动、换行切换、展开为大编辑窗口；展开前后共用同一编辑缓冲，不能丢内容。重建骨架前说明将覆盖什么并确认，取消不改动，确认后可撤销。完整语法补全与新编辑器依赖不是本期交付前提。

连接/LLM/凭据下拉必须区分加载中、加载失败、未配置、已加载。失败给重试；未配置给可点击的配置入口并保留编辑现场。不能将请求失败显示成“没有配置”。Python 实现页始终显示“由大模型推演，非本地 Python 执行”；计算节点按实际选用的引擎说明。

## 5. 普通选择、绑定、测试是三种不同操作

### 5.1 普通选择

列表名称和画布节点点击始终用于查看详情。当前查看节点 `selectedId` 与测试范围 `testNodeIds` 分开。批量测试选择不剥夺查看配置的能力。

### 5.2 建立绑定

1. 点击“建立绑定”，模式栏显示“先选来源节点，再选目标节点；Esc 退出”。
2. 点击源、目标后，打开参数绑定对话框；展示来源输出、目标输入及类型。
3. 确认才写入目标输入 binding 并派生连线；取消不创建边、不修改数据。
4. 通过现有校验处理自引用、环、类型不符等；不新增另一套规则。
5. 已有连线点击可查看绑定；删除列出受影响参数并确认。多条参数形成的边不能无提示清掉全部绑定。

### 5.3 测试所选节点

- 按钮命名为“选择测试节点”，避免“连续链”暗示必须线性：当前编排可以有分支依赖。
- 进入后列表和节点显示独立勾选控制，节点名称点击仍查看详情。绑定模式和测试范围模式互斥。
- 模式栏持续显示已选数量、测试所选节点、退出；执行顺序按依赖拓扑确定，不按点击顺序。
- 允许先选下游节点，再提示缺少哪些上游。提供“补选所需上游”显式操作，不静默扩大执行范围；缺依赖/存在环时不能开始范围测试。
- 独立测试单节点仍可手工提供来自上游的输入，不要求运行真实上游；固定值在测试表单中只读，不能显示可改但运行时忽略。
- Esc 优先关闭最上层弹窗，再退出操作模式，最后才交给全局。输入区的文本撤销仍归输入控件，不能误撤销整个编排。

## 6. 检查与问题定位

“检查配置”只做校验，不执行 SQL、HTTP、Redis 或 LLM。

检查结果进入独立问题面板，每条为：严重级别、节点名称、字段中文名称、原因、去处理。列表与画布节点标记问题数量，除颜色外有文字/符号。

例：`错误 · 计算 SOC · 输入「额定容量」：尚未选择来源 → 去处理`。点击后打开节点详情的“输入”页签，展开对应参数、滚动聚焦并短暂高亮字段。来源连接失效时引导到实现页的连接控件；编排输入/输出问题打开边界配置。未知位置至少定位到相关节点，不跳空白页面。

当前后端只有 `errors/warnings/items` 归组。本期允许增加结构化 `diagnostics`，旧返回字段内容及顺序保持兼容。建议结构（仅 API 返回，不存草稿）：

```json
{
  "code": "INPUT_BINDING_MISSING",
  "level": "error",
  "message": "输入「额定容量」尚未选择来源",
  "kind": "node",
  "id": "稳定节点ID",
  "section": "inputs",
  "field": "binding",
  "parameterId": "稳定参数ID"
}
```

`section` 只取页面已有区块；编排级、连接级问题允许没有 parameterId。按 `(code,kind,id,parameterId,field)` 构建稳定问题键。不能从错误消息里的中文反推字段路径。新增诊断只为定位，不借机修改校验业务规则。

状态约定：未检查 → 检查中 → 有问题/通过；任何影响配置的修改变为“配置已修改，待重新检查”。纯布局与缩放不失效。过期问题保留可查但标记“上次检查”，不把它计为当前已确认结论；重检后更新徽标。

每次请求记录编排 ID、配置代际和相关上下文，晚到的旧回包不得覆盖当前结果。保存返回的 check 与主动检查必须遵守相同快照规则，不能相互覆盖出假“通过”。切换项目/编排、撤销重做、连接有效性改变也需正确处理新鲜度。

## 7. 测试、运行与本次结果

| 入口 | 唯一位置 | 范围 |
|---|---|---|
| 运行全部 | 页面头部 | 编排整体 |
| 测试此节点 | 处理节点详情头部 | 当前一个节点，手工提供必要输入 |
| 测试所选节点 | 测试模式栏 | 当前勾选且依赖完整的一组节点 |

列表不再放测试按钮。测试/运行弹窗写清范围、项目上下文、必要输入及真实调用性质；复用最近一次未提交输入，不无故清空。

无输入的纯计算/明确只读范围可直接执行，避免空表单。存在允许写的 SQL、写 Redis、可能有副作用的 HTTP 或无法确认性质的调用时，把执行摘要确认整合进原测试/运行弹窗，不额外套多个确认窗口。这是对已有实际执行的说明，不新增执行权限机制。“不保存草稿”不等于“不会修改外部系统”。

数值、是/否、数组、对象的输入提示使用中文类型；数组示例 `[]`、对象示例 `{}`，未选的必填布尔值不能悄悄变为 false。客户端基础类型验证通过后才提交，后端继续权威校验。

运行基于提交时的配置快照。结果面板显示测试范围、提交时间、结果、耗时；运行期间只有全局“执行中”，节点最多标“本次目标/等待结果”，不能把所有节点提前标成真实运行中。现有接口非流式，本期不增加伪实时动画或进度百分比。

结果返回后按真实成功/失败/跳过状态展示；自动定位首个失败节点并打开结果详情。结果关联此次测试范围，未参与节点不能借用上轮成功状态。修改配置后保留“上次快照结果”标识，不能作为当前配置通过的证明。切换编排后旧请求不污染新编排。

弹窗具备初始焦点、Tab 焦点约束、Esc、关闭后焦点返回。点击遮罩不静默丢弃测试参数；存在未提交修改时提示保留/放弃。运行中的关闭仅关闭视图，不宣称已取消后端任务。

## 8. 原型阅读方法

原型覆盖：按需详情、节点列表、输入/实现/输出/高级页签、绑定模式、测试范围独立勾选、问题定位与过期、展开代码、运行结果面板。

初始例子是“查询额定容量 → 计算设备 SOC”，缺少计算节点输入和编排输出两个绑定。先点“检查配置”观察问题，再点“去处理”，填写来源后重检。示例数字只用于表现 UI，不表示已验证业务公式或已连真实数据。

原型为静态交互模拟：不调用 API、不保存用户数据、不执行 SQL/Python/Redis/HTTP/LLM。缩放、绑定和执行只演示选定场景；正式实现必须复用实际 Cytoscape、类型校验和执行 API。原型未演示的五类节点细节以当前实现为准，不允许据此删除。

## 9. 验收清单

| 编号 | 场景 | 通过标准 |
|---|---|---|
| A01 | 1440×900、1366×768、1280×800 | 未选中不占详情宽，选中可读，无整页横向滚动，工具栏不盖节点 |
| A02 | 1024×768 | 列表与详情使用抽屉/覆盖，不能垂直堆出长页面 |
| A03 | 选择节点、返回结果、开关详情 | 用户视口不无故 fit；全图与100%由用户控制 |
| A04 | 配置检查发现输入/实现/输出错误 | 数量、列表、节点标记一致；点击问题到对应字段 |
| A05 | 检查中编辑、切换编排/项目 | 旧响应丢弃或仅作为旧快照显示，不冒充当前通过 |
| A06 | 改布局 vs 改参数 | 前者不使检查失效；后者立即待重检；保存返回检查遵守相同规则 |
| A07 | 建立/取消/删除绑定 | 保持唯一 binding 真相；取消零改动；删除有影响确认，可撤销 |
| A08 | 范围测试选中下游 | 缺上游有明确清单；显式补选；仍能点击节点查看详情 |
