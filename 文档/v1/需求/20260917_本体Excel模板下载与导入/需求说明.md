# 本体 Excel 模板下载与导入

版本：v1，2026-09-17。状态：待实施。本次交付为需求、原型及实施指令，不代表工作台已具备此功能。

## 1. 本期目标

用户在当前本体的「工作概览」下载空白 Excel 模板，填写对象、属性、规则、动作，上传后查看检查结果，选择同名处理策略，再一次性导入当前本体草稿。

核心原则：填写业务内容即可，不要求用户填写编号、内部 ID、关联编码或技术字段。不覆盖现有内容，不自动发布，不操作项目映射。

### 交付文件

- [交互原型_v1.html](交互原型_v1.html)：交互与状态参考。示例预览为模拟，不解析真实 Excel，不写入工作台；下载链接指向真实模板。
- [开发计划.md](开发计划.md)：技术方案、任务边界与验收。
- [执行指令.md](执行指令.md)：给其他 harness 的完整执行入口。
- 模板原件：`../20260917_本体Excel导入模板/本体模型填写模板_v2.xlsx`。

模板原件已包含数据类型下拉与观测值类型联动。实施时必须复制这份文件作为运行资产，不得重新生成另一套表头或去掉联动。

## 2. 入口与操作

### 入口

本体区「工作概览」顶部工具区增加两个按钮：**下载 Excel 模板**、**导入 Excel**。不新增一级菜单，不改项目区。

已选本体时导入到当前本体。没有选择本体时仍可下载模板；导入入口禁用并说明「请先选择或新建本体」。无本体空态入口按现有 App 空态布局接入，不再加一套本体选择器。

### 导入面板

打开约 960px 宽的对话框（窄屏全屏），单面板完成，不做三步向导：

1. 标题「导入本体内容」，固定显示「导入到：储能本体 · 当前草稿」。
2. 上传区域：选择或拖拽一个 `.xlsx` 文件，展示文件名、大小；可更换。旁边保留下载模板入口。
3. 两个单选卡片设置同名策略，默认「跳过同名内容」。
4. 文件或策略变化后，点击「检查导入内容」；检查期间显示进度状态、禁止重复操作。
5. 同一面板展开预览：新增、跳过、自动重命名、错误数量，以及可按「全部／新增／跳过／自动重命名／问题」筛选的清单。
6. 底部显示「导入 N 项」及「取消」。只有已检查、无阻断问题且 N > 0 时允许确认。N = 新增数量 + 自动重命名数量，不能把重命名重复计数。
7. 点击确认后一次保存；成功展示四类分别新增多少、跳过多少，提供对象建模／共享属性／业务规则／动作定义入口。结果区不再保留可重复点击的导入按钮。

预览列：工作表、Excel 行号、原名称、导入后名称、处理结果、说明。问题定位示例：`属性 · 第 6 行 · 观测值类型：数据类型为时间序列，请选择文本、数值、是／否或时间。`

不在工作台内新增一个 Excel 表格编辑器。出错后回 Excel 修改并重新上传。更换文件或切换策略使旧预览失效；不能拿旧清单提交新文件。

## 3. 同名处理策略

| 选项文案 | 补充说明 | 行为 |
| --- | --- | --- |
| **跳过同名内容**（默认） | 已有同名定义时保留现有内容，不导入重复项。 | 重复行标为「跳过」，不覆盖、不合并、不更新现有定义。 |
| **保留并自动重命名** | 同名内容仍导入，名称末尾自动添加随机数字。 | 重复行标为「自动重命名」，如 `额定容量_482731`；作为独立新定义导入。 |

### 同名判定范围

- 仅比较**当前本体草稿内的同一类别**；不跨本体，不跨四种类别。
- 属性仅和当前本体的**共享属性库**比较；对象私有属性不参与。导入属性全部成为共享属性。
- 规则和 `workflow.businessRules` 比较，不和项目取值规则、SQL 规则或计算实现比较。
- 动作和 `workflow.actions` 比较，包括历史格式动作；同名跳过时不触发历史格式转换。
- 对象和对象类型比较，不和具体项目实例比较。
- 名称去除首尾空白后比较；保留内部空格，英文大小写敏感。不做模糊匹配或语义合并。
- 同一 Excel 内重复也执行相同策略，按各 Sheet 自上而下处理。第一条可导入的名称占位，后续行视为重复。
- 不同类别均叫「停止充放电」不构成同名冲突。

### 随机后缀

推荐格式：`原名称_六位随机数字`。在当前类别已有名称、文件内待导入名称以及已生成名称范围内检查唯一性；碰撞重试，100 次仍失败则显示具体错误，不使用可能冲突的名称。

必须预先保留本批用户原始名称，防止随机生成的名称抢占文件中另一行本来就填写的名称。生成名超出现有名称长度约束时说明问题，不截断用户名称。

同一份有效预览中的名称和系统 ID 固定；确认、失败后重试不能再生成另一批随机名字或 ID。重名清单中的原始定义保持不变。

## 4. 模板与字段

模板可见内容保持四个工作表及第一行表头，后续为空。不要恢复示例、编号、关联列、说明大段文本或对照区。

| Sheet | 表头（与模板一致） | 必填与解释 |
| --- | --- | --- |
| 对象 | 对象名称、业务定义 | 两项必填。 |
| 属性 | 属性名称、业务定义、数据类型、观测值类型、显示格式 | 前三项必填；仅时间序列要求观测值类型；显示格式选填。 |
| 规则 | 规则名称、业务定义、规则内容、输出结果 | 四项必填，自然语言描述。这里是本体业务规则。 |
| 动作 | 动作名称、业务定义、业务效果 | 三项必填。不新增参数、提交条件或项目接口字段。 |

### 属性枚举及落库语义

| Excel 文案 | 本体数据类型 |
| --- | --- |
| 文本 | string |
| 数值 | double |
| 是／否 | boolean |
| 时间 | dateTime |
| 数组 | array |
| 结构体 | struct |
| 时间序列 | `{type: "timeSeries", valueType: ...}` |

观测值类型仅四项：文本/string、数值/double、是／否/boolean、时间/dateTime。兼容用户手输的「是/否」为同一枚举，不把英文类型名或其他近义词静默当成有效选项。

数组和结构体按现有工作台允许的基础定义保存，本期不发明子字段协议或要求模板新增列。

「显示格式」非空时作为自然语言规则保存：`{mode:"natural", instruction: 单元格原文}`，复用现有 `mg:formatting` JSON-LD 包装与序列化；为空不生成配置。不调用 LLM，不执行格式化，不解析为代码，也不强猜成常用格式。

### 模板联动

属性页 C 列为数据类型，D 列为观测值类型。C = 时间序列时 D 可选四项，否则无可选值。原件范围是第 2～1001 行。

无宏 Excel 切换 C 列不会自动清除 D 列旧值，原模板会标红提示；导入必须再次检查，不能因为是模板就信任单元格。非时间序列且观测值类型非空时阻断该批导入，并明确要求清空。不新增宏。

隐藏的 H 列是模板联动所需枚举区。**解析时只读取模板表头对应的业务列，忽略 H 列等隐藏辅助区；不得把隐藏枚举行当成导入记录。**

## 5. 文件与内容校验

### 文件约束

- 一次选择一个 `.xlsx`。拒绝 `.xls`、`.xlsm`、CSV、加密文件、损坏文件。
- 本期文件压缩后不超过 1 MiB，四表合计不超过 1000 条非空业务行（不含表头和隐藏辅助内容）。提示具体限制，禁止静默截断。
- 必须保留四个 Sheet。每个 Sheet 可只有表头，也可只填写其中一类；不要求四类都填。
- 表头按名称识别，允许调换业务列顺序、去除表头首尾空白；缺少任一约定表头或重复表头报错。无内容的表也要有完整表头。
- 隐藏辅助列忽略；额外可见列/额外 Sheet 若有用户数据，报「存在模板以外内容，本次无法导入」并列位置，避免悄悄丢数据；纯空额外区域忽略。
- 文件中仅有下拉、样式或格式的空行不算记录。读取四个业务区域，不按整张表的 usedRange 生成记录。
- 业务列中的 Excel 公式、错误值、合并的数据单元格均阻断，提示位置；不执行公式，不使用公式缓存值。枚举联动公式属于数据验证，不属于业务单元格公式，不应误拒绝。
- 文本字段接受文本；误填日期、数值、布尔等类型时指出字段需填写文字，不擅自改写。名称和必填检查以 trim 后内容为准，正文保留内部换行。

### 行校验顺序

1. 检查文件结构、业务单元格安全及名称；名称空的非空行是问题，不能借跳过策略隐藏。
2. 按名称归类。在「跳过」策略下，已确定不会导入的重复行不再因其业务定义等缺项阻断，但仍显示跳过原因。
3. 对真正待导入行检查全部必填与类型规则。例：新动作缺业务效果、时间序列缺观测值类型。
4. 任一待导入行有问题，**整批不写入**；不要默认部分成功。用户修复 Excel 后重新检查。
5. 全部为空：提示「模板没有填写内容」；全部同名被跳过：提示「没有可导入的新内容」，不能生成空修订。

导入前检查最终保存请求的 UTF-8 字节数，包含现有草稿，不得突破现有服务 2,000,000 字节上限。超限提示减少批次；若现有草稿已经接近上限，需说明原因，禁止提高全局上限绕过。

## 6. 导入范围与关联

- 对象只建立名称和业务定义。
- 属性全部进入共享属性库，独立于任何对象。
- 规则进入本体业务规则库；动作进入动作定义库。
- **不自动建立对象—属性、对象—规则、对象—动作关系，也不生成对象间链接。** 模板没有关系信息，不能根据同名或文字推断。
- 导入成功后的提示：「已保存到当前本体草稿。可在对象建模中关联共享属性、规则和动作。」
- 不创建新本体，不修改当前项目引用，不执行计算或动作，不发布版本。
- 保留现有全部定义、关联、未知扩展字段、项目数据、连接密码以及已发布快照。

这是本期范围决定；后续如需 Excel 描述关系，单独讨论，不在本次偷偷增加关联编码。

## 7. 保存与失败行为

- 检查预览、取消、更换文件均不写入本体状态和用户目录。
- 预览绑定当前本体 ID 及草稿基线；本体或草稿内容变化时预览过期，要求重新检查。
- 确认导入调用现有本体表单保存链路，一次 mutate 合入全部新增定义、一次提交形成草稿修订；不逐行 POST，不另建一套数据存储。
- 成功必须以保存成功为准，界面关闭/列表刷新不等于成功。导入可作为一次现有撤销操作，但不额外开发导入历史或批次管理。
- 409 冲突时保留原文件与策略，提示重新读取并检查；不得自动覆盖较新的草稿，不沿用失效的重名判断结果。
- 网络断开可能发生在服务端已保存之后，提示「导入结果待确认」。用本次固定新增 ID 集合与内容对比读取回来的最新草稿：全部一致则确认已导入；全部不存在则重新检查后再提交；部分存在或内容变化则提示人工核对，不能无脑再次导入。
- 保存过程中锁住重复提交和更换文件；离开面板采用现有表单守卫。错误清单可以保留供查看，切换本体后不能仍向旧目标提交。

## 8. 验收标准

| 编号 | 验收 |
| --- | --- |
| A01 | 概览及无本体空态能下载模板，下载文件与模板原件一致，四表表头、下拉及联动保留。 |
| A02 | 四类各导入一行，分别出现在对象、共享属性、业务规则、动作库，刷新后仍存在。 |
| A03 | 只填写一个 Sheet 也能导入，其他表保持空表头。 |
| A04 | 现有同类同名、文件内同名执行两种策略；跨类别同名互不影响；空格与大小写判定符合文档。 |
| A05 | 自动重命名清单在确认前可见；随机碰撞重试；保存后的名称/ID与预览一致；现有项不变。 |
| A06 | 非时间序列保留观测值、时间序列缺观测值、必填缺项、错误枚举均准确定位工作表/行/列，整批零写入。 |
| A07 | 下载模板的隐藏 H 列不会被误导入；空行、数据验证范围不产生多余记录；未知有数据的可见列不会被悄悄丢弃。 |
| A08 | 普通属性及时间序列类型往返不丢字段；显示格式自然语言原文保存；导入不调用大模型。 |
| A09 | 取消、只检查、全空、全跳过不产生修订；更换文件/策略/本体后旧预览不能提交。 |
| A10 | 一次导入只保存一次，重复点击不生成第二批；刷新核验结果与导入数量一致。 |
| A11 | 409不覆盖；网络结果不明时先核对固定ID，不能重复生成后缀。并发测试用隔离数据。 |
| A12 | 现有对象属性/动作/规则关联、项目数据、发布版本不变；不自动创建本次四类之间的关联。 |
| A13 | 文件超限、业务行超限、损坏/加密/错误格式/业务公式、保存请求超限都有明确提示。 |
| A14 | 完成真实浏览器上传—检查—导入—刷新验证；仅原型或类型检查通过不算功能完成。 |
