## 6. 已知事项与遗留

1. **B2 报告的行为疑点（只记录，未修改，保持机械提取纪律）**：a) 「契约被属性来源引用但尚无实现」警告疑似不可达（referenced ⊆ implemented 恒成立）；b) 非法结构（object_bindings 非 dict 条目、properties:null、无 id 的 implementation 等）会使校验抛异常而非产出错误项——上游 `_normalize`/保存路径未放开这些形态，风险低，如需加固应作为独立行为修复并先写复现；c) 实现错误过滤词「未声明」匹配不到实际文案「未在该实现中声明」（该问题只进 items 不进 errors，金样已锁定现状）。
2. 保存队列的 409「以当前内容重试」仍要求用户显式确认（UI 二次确认语义未变）；双标签页 409 全链路浏览器演练未在本轮执行（队列级已有 ④ 组覆盖）。
3. `service/` 转发垫片与 `/api/project-config`（仅历史组件使用，组件已删但接口按兼容要求保留）待确认无外部调用方后清理。
4. 首页 URL 默认 `?ontology=storage` 与用户实际 UUID 本体 id 不匹配时空白本体提示——迁移前即存在的现状（工作概览会引导打开列表中的本体），未在本轮范围。
5. tools/legacy 脚本内部 `imports/`、`outputs/` 相对路径未改写（不执行的历史脚本，路径映射见迁移清单）。
