  • 添加模型 = 单弹窗（参照用户提供截图）：供应商下拉（仅支持 OpenAI 兼容协议 API；预设目录 + 搜索 + 「其他 → 自定义」）→ API Key（密文输入、可测试连接）→ 模型名称（预设供应商 = 内置目录下拉；自定义 = 手填接口地址 + 模型参数名）。
