# 储能本体建设：教学示例

这是一份按现有储能材料整理的学习模型，无需先做现场审核即可学习流程；不用于生产控制。

## 边界

纯本体包括对象类型、属性和关系。观测/指标有语义定义，但计算实现、SQL、Redis键、项目参数不属于纯OWL本体。不能把“有业务意义”误等于“应画成对象类型”。

## 默认画布

6类：园区、储能电站、储能资源组、储能设备、电池簇、线路分段。
电压、电流、额定功率、额定能量显示在设备节点属性中。SOC等放到观测/指标，算法放到规则契约。

## 完整走通一次

1. 明确问题：查询某电站指定时刻SOC。
2. 识别事物：电站、设备、电池簇；需要的范围和计划对象另建。
3. 定义关系和属性：所属电站、所属设备、容量基准。
4. 定义指标与规则：SOC容量加权、质量和时间政策。
5. 绑定模拟实例：南区两设备两簇。
6. 验收：50%×100与80%×200，聚合70%。

## 示例假设

- 设备包含电池簇；园区包含储能电站。
- 储能系统在本例解释为逻辑资源组。
- m_load按负荷计量边界解释，不假定是变压器。
- SOC例采用已知能量容量基准和百分数表示；不表示现场BMS已核实。
