# 结构化查询规则编辑

入口：项目映射 → 取值规则库 → 新建查询规则 / 编辑规则实现。

## 填写顺序

1. 规则名称、项目数据库连接。
2. 输入参数：名称、数据类型、说明、传入方式。绑定参数在属性取值中填写；运行参数由查询调用方传入。
3. 查询步骤：名称、预期一条或多条、查询表、AND 条件、输出字段与别名、可选排序。
4. 返回结果：最后一步的单值或时间序列，值类型及输出字段。
5. 保存取值规则，直接进入项目草稿；取消不修改已保存配置。

固定表及字段使用连接目录下拉；切换固定表会清空旧固定字段。动态表/字段通过前面唯一记录步骤的输出引用。结构参考表只辅助编辑，不作为运行表。目录缺失时允许输入标识，明确提示未验证。

## 兼容和校验

- 新编辑保存使用项目规则 schemaVersion 3；本体协议不变。
- 旧版本保持读取兼容。打开编辑时在内存转换，保存才写入新修订，规则 ID 不变。
- 旧标准采样流程仍完整保留：s_attr_scada → 动态测点表 → 动态采样表。
- 输出改名同步更新规则内部引用；删除被引用输出、无效参数引用、前向引用、引用多条记录步骤会阻止保存。
- 新参数会在属性绑定页显示；既有绑定缺少参数时校验提示，不自动猜测值。
- 单值结果最后一步要求一条记录；时间序列要求多条，并选择不同的时间、值字段，按时间升序。
- 规则的输出引用仍保留历史稳定键 series（包括 V3 单值），界面按实际类型显示，不因升级破坏已有引用。

本次实现配置创建、编辑和校验，不执行 SQL、不让 LLM 执行规则。运行输入类型和动态表字段的真实存在性仍须执行器验证。
