# 计算函数实施记录

日期：2026-09-16。依据《GLM执行指令_计算函数_20260916》完成：取值规则库「新建规则」支持「SQL 查询 / 计算函数」二选一；计算函数 = 名称 + 业务说明 + 多输入 + 一条公式 + 一个输出 + 示例试算（纯公式计算）。不需要数据库连接、数据表与适用对象。全程不执行 SQL、不做属性数据查询、无文件/网络访问。

## 1. 数据协议（kind=calculationFunction，冻结）

```json
{"kind":"calculationFunction","schemaVersion":1,"id":"cf-…","name":"计算 SOC","description":"选填",
 "inputs":[{"id":"inp-…","name":"剩余电量","type":"number|string|boolean"}],
 "implementation":{"language":"calc-expression-1","expression":"{inp-…} / {inp-…} * 100"},
 "output":{"id":"out-…","name":"SOC","type":"number"}}
```

存入现有项目 implementations 容器，与 SQL 规则一起展示；不写本体、不复制函数到属性绑定。**公式内部只引用参数稳定 ID（`{inp-…}`）**：编辑器显示/输入用 `{参数名}`，保存前后端转换（引号外记号扫描，非字符串替换）；改名只改 name 字段、公式不动；删除被公式引用的参数在保存时被阻止（本地 calcFunctionErrors + 后端 parse 双重拦截）。属性绑定落 `properties[属性键] = {kind:"computed",mode:"calcFunction",implementation,output,inputs:{参数ID:{from:"property",property}|{from:"constant",value}}}`，引用全部稳定 ID。

## 2. 表达式语言与边界（权威实现在后端 workbench/calc_functions.py）

- 语法：数值、'文本'（'' 加倍）/“文本”、true/false、`{参数ID}`、括号、一元负号、+ - * /（仅数值）、比较 = != < <= > >=（结果是/否）、函数 IF(3)/MIN(≥2)/MAX(≥2)/ABS(1)/ROUND(1–2,小数位 0—6)/ERROR(1,文本)。
- 类型：数值/文本/是否；仅相容运算，**文本不隐式转数值**；IF 条件必须是否、两分支同型（ERROR 分支视为任意型）；ROUND 四舍五入（.5 向上）。
- 惰性：IF 只求值选中的分支——`IF(b>0, a/b*100, ERROR("额定容量必须大于零"))` 在 b=0 时报 ERROR 文案而非除零（A4 有专项断言）。
- 硬限制：长度≤500、嵌套≤20、节点≤200；拒绝 NaN/Infinity（含字面量 1e999 与运算溢出）；非法语法、非白名单函数、属性访问、赋值一概拒绝。
- 前端不重复实现公式执行：保存前调 `/api/calc-eval`（validateOnly）做权威语法/类型校验，试算同路由带值求值。
