## 2. 冻结的配置样例（阶段 0）

```jsonc
{"mode":"builtin","style":"percent","percentInput":"hundred","decimals":1}          // A4 实测 70.56 → 70.6%
{"mode":"builtin","style":"standard","decimals":2,"grouping":true,"suffix":" kW"}  // A5 1234.5 → 1,234.50 kW
{"mode":"builtin","style":"template","template":"ESS-{value}"}
{"mode":"builtin","style":"mapping","mappings":[{"from":"running","to":"运行中"}]}
{"mode":"builtin","style":"series","timeFormat":{"style":"datetime","precision":"second","timezone":"Asia/Shanghai"},"valueFormat":{"style":"percent","percentInput":"ratio","decimals":1}}
{"mode":"natural","instruction":"输入为 0—100 的 SOC…"}
```
新增键：`template / mappings / maxItems / elementType / elementFormat / fields / timeFormat / valueFormat`；新样式 `template / mapping / list / join / scientific`（`pairs`/`series` 沿用旧名赋新义）；`decimals` 固定精度优先于旧 `minDecimals/maxDecimals`。

**与冻结契约的已裁决偏离**：`legacyStyleLabel(kind, config)` 实际接收配置对象而非样式字符串（number 历史需读 `notation`）；未知样式回退显示原样式名（组件以「历史样式：xxx」只读呈现）。测试已按实际签名同步。
