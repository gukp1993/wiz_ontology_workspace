## 3. 问题清单

### P1 — 左侧导航栏溢出，最后两个页面入口不可用（布局 bug）

**现象**：1000px 高视口下，导航容器在 y=900 处被其父容器裁剪：

| 按钮 | 位置（top~bottom） | 状态 |
|---|---|---|
| 本体与版本管理 | 875 ~ 915 | 底部裁掉 15px，勉强可点 |
| 历史图谱导览 | 917 ~ 958 | **整体位于裁剪线之下，完全不可见** |

点击"历史图谱导览"位置实际命中的是覆盖其上的"本地工作空间"页脚（`DIV.rail-bottom`）——**该页面在默认视口下无法通过导航到达**。已用 hash 路由（#learning）验证页面本身渲染正常，问题纯属导航布局。

nav 内部虽可滚动（scrollHeight 723 vs clientHeight 663），但无滚动条或任何提示；屏幕更矮时会有更多按钮不可达。

**建议**：导航区改为自适应滚动（flex 收缩 + `overflow-y:auto` + 可见滚动条样式），或压缩按钮密度 / 分组折叠。

### P2 — 体验改进建议

| # | 问题 | 说明与建议 |
|---|---|---|
| 1 | 校验错误暴露原始系统标识 | 如"mg:object_55de5b7096d645d7a71e52f858963cdd 缺少名称"，业务用户无法对应到具体对象。建议错误信息附带显示名（如"未命名对象"或当前名称） |
| 2 | 状态消息滞留过期内容 | 修复错误后顶部 feedback 仍显示旧的"待修复：…缺少名称"，直到下一次操作才刷新 |
| 3 | 撤销/重做粒度过细 | 字段级快照导致 redo 无法恢复完整"创建+填写"动作：测试中 redo 后对象名称回退为空并触发校验错误。建议对"新建定义"类操作做合并快照 |
| 4 | 无删除本体的 UI 入口 | 测试创建的本体只能手动删除 `ontology/workspaces/<id>/` 目录 |
| 5 | API 错误码分类 | 未知接口与未知 ontology id 均返回 400 而非 404 |

### 测试环境说明（非应用问题）

自动化测试工具在此环境下物理点击偶发丢失、截图管线不稳定。所有结论均以 DOM 状态、磁盘产物和 API 响应为最终依据，不受环境影响。

## 5. 审阅与定向修订记录（2026-09-09）

本节保留原始测试记录，并修正其结论范围。原报告应定位为**首轮冒烟测试记录**，而不是全功能验收结论。

| 原问题／结论 | 核实结果 | 本轮处理 |
|---|---|---|
| 八步流程全部可用 | 明细未覆盖全部八类内容的写入、保存和重载 | 收窄为基础建模与版本闭环冒烟通过，完整验收待补 |
| 导航末项不可达 | 存在滚动但缺少明显提示；不能仅按初始裁剪认定绝对不可达 | 桌面导航固定为剩余高度独立滚动，增加滚动条，页脚不收缩 |
| 错误只显示系统标识 | 属实，业务用户难定位 | 顶部错误和验收错误补充业务名称／未命名资源类别，保留标识便于追溯；直接点击定位尚未实现 |
| 状态消息过期 | 属实，编辑不使旧结果失效 | 修改后标记旧消息过期，清除验收页旧报告 |
| 撤销粒度 | 字段聚焦即记录快照，未修改也影响重做栈；“一次重做应恢复全部填写”不成立 | 通用 EditorField 改为首次实际输入前记快照、失焦结束编辑事务；未强行合并创建和全部字段填写 |
| 无删除本体 | 需求边界，非已承诺功能失效 | 需求明确 V1 不提供该入口，不新增删除能力 |
| 未知本体返回 400 | 非法格式与不存在资源应区分 | 实测非法字符串 400；合法但不存在的 UUID 404；保持现状 |
| 未知接口返回 400 | POST 可能先校验请求体，报告缺少请求方法和负载 | 暂不变更；补用例后再决定路由与请求校验顺序 |
| 快照自包含 | 仅定义恢复包，不包含全部执行与接入环境 | 修正表述，不作为完整部署包验收 |
| 无安全暴露／无损坏 | 测试覆盖不足以作全局结论 | 改为本次已测用例未发现 |
