## 4. ontology：你的真实数据

它与frontend/src/ontology不同：前者存数据，后者是编辑数据的页面。

### 数据目录怎么生效

| 目录 | 作用 |
| --- | --- |
| workspaces/<本体ID>/ | 本体名称/ID登记，不存整份模型 |
| drafts/models/<本体ID>/ | 本体草稿；current.json指向当前修订 |
| drafts/projects/<项目ID>/ | 项目映射草稿；current.json指向当前修订 |
| releases/models/<本体ID>/ | 本体不可变发布版本，项目固定引用其中一个 |
| releases/projects/<项目ID>/ | 项目不可变发布快照 |
| models/ | 本体初始化/旧基础输入，目前为空 |
| projects/<项目ID>/ | 项目初始化配置，不是当前编辑副本 |
| catalogs/projects/<项目ID>/ | 连接的表和字段目录缓存 |
| vault/projects/<项目ID>/ | 服务管理的受保护密码，不进入发布快照 |

上表路径均位于根目录ontology/之下。

### 本体文件分别放什么

| 文件 | 内容 | 示例 |
| --- | --- | --- |
| workspace.json | 本体工作区登记 | 名称、稳定ID |
| current.json | 当前草稿修订指针 | 应读revisions下面哪一份 |
| ontology.json | 通用本体结构 | 储能簇、所属设备链接、SOC属性、共享属性 |
| workflow.json | 通用计算契约、动作/接口等定义 | 查询储能簇SOC的输入输出 |
| layout.json | 图画布布局 | 节点坐标等 |
| metrics.yaml | 旧指标格式兼容文件 | 可以为空 |
| rules.yaml | 旧规则格式兼容文件 | 可以为空；新契约不都在这里 |
| manifest.yaml | 发布版本元信息 | 版本号、变更类型、摘要等 |
| index.json | 本体发布版本索引 | 发布列表与最新版本定位 |

**现在主要持久化格式是ontology.json；并非全部本体内容都在一个ontology.jsonld中。** 编辑器内存仍用JSON-LD，由转换层连接两种格式。空metrics/rules可以不写入发布版本，发布目录文件比草稿少是正常的。

### 项目文件分别放什么

| 文件 | 内容 | 储能例子 |
| --- | --- | --- |
| project.yaml | 项目身份、引用本体版本 | 某储能项目引用某本体版本 |
| connections.yaml | 数据连接地址/引擎等，不含明文密码 | MySQL、Redis连接 |
| bindings.yaml | 对象识别、来源、属性取值和链接映射 | 储能簇主键；额定功率字段；SOC的Redis key模板 |
| implementations.yaml | 通用计算契约在该项目的具体实现 | 查询SOC的输入、处理规则与输出 |
| parameters.yaml | 项目参数 | 供来源或计算规则使用的常量 |
| current.json | 项目当前草稿指针 | 最近成功保存的修订 |
| manifest.yaml | 项目发布快照元信息 | 版本、引用本体版本和发布记录 |

**配置SOC取值来源 → bindings.yaml；定义“查询SOC”的通用签名 → 本体workflow.json；配置项目里的具体计算处理 → implementations.yaml。**

不要手工挑某个revisions修改，也不要把重复文件直接清理掉。它们是你的保存历史；当前使用哪份由current.json决定。

## 10. 改功能时怎么定位

| 需求 | 优先看前端文件（frontend/src下） | 可能关联后端（workbench下） |
| --- | --- | --- |
| 下拉框样式 | shared/AppSelect.vue、style.css | 通常无 |
| 对象名称/定义 | ontology/ObjectWorkspace.vue | 新增持久化字段才涉及格式转换 |
| 图的节点/连线 | ontology/ObjectCanvas.vue、graphAdapter.ts、shared/graphStyle.ts | 通常无 |
| 属性表单 | ontology/PropertyManager.vue、propertyModel.ts | properties.py、model_format.py |
| 显示格式 | ontology/PropertyFormatting.vue | formatting.py、formatter_runtime.cjs |
| 通用计算输入输出 | ontology/FunctionManager.vue | contracts.py、workflow.py |
| 数据库/Redis属性取值 | project/PropertySources.vue、bindingModel.ts | project_validation.py |
| 项目计算实现 | project/ImplementationManager.vue | project_validation.py |
| 链接字段关联 | project/LinkMappings.vue、bindingModel.ts | project_validation.py |
| 连接测试/表结构 | project/ConnectionManager.vue、api.ts | project_routes.py、dbdrivers.py |
| 保存与冲突 | app/saveCoordinator.ts及调用页面 | projects.py、workspaces.py及routes |
| 发布 | 两区Release/Validation页面 | versions.py、projects.py、contracts.py |
| 菜单和跳转 | app/navigation.ts、App.vue | 通常无 |

这是定位表，不要求每次把相关文件全改一遍。简单界面修改通常不涉及数据文件和后端协议。
