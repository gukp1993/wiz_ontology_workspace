# 本体工作台介绍与菜单说明

日期：2026-09-20。适用版本：当前 `main` 分支工作台（http://127.0.0.1:18765）。本文面向使用者，说明工作台是什么、两条主线怎么走、每个菜单页做什么。

---

## 1. 工作台是什么

工作台用于**建设企业业务本体，并把本体映射到具体数据源**。它把「业务上有哪些对象、它们之间什么关系」与「这些数据实际存在哪张表、哪个 Redis Key」分开管理：

- **本体区**回答"业务上有什么"：对象类型（储能设备、充放电计划…）、属性、对象间链接、业务规则、动作。
- **项目区**回答"数据从哪来"：为某个具体项目，把本体对象对应到数据库表、字段、Redis 或函数编排。

两者是**两条独立的数据线**：各自有独立的草稿、发布版本和并发控制；项目只引用本体的**已发布版本**，本体草稿怎么改都不会影响项目，升级由项目主动发起。

**边界**：工作台只做定义与映射配置，**不执行业务查询、不修改业务数据库**。数据连接的"测试连通性/读取表结构"是唯一的真实网络探测，且只做固定只读操作。真实业务数据留在你自己的库里，工作台不搬运。

---

## 2. 先理解三个概念

| 概念 | 含义 |
| --- | --- |
| **草稿 vs 发布** | 所有编辑先落在"草稿"上（自动保存，可撤销）；确认无误后"发布"形成**不可变版本**（本体用 1.0.0 语义化版本，项目用 v1、v2…）。发布后的版本永不改写。 |
| **引用用稳定 ID** | 对象、属性、链接、规则、动作之间用系统生成的稳定 ID 互相引用；改显示名不会断链。 |
| **归属** | 所有数据按登录账号完全隔离：A 账号看不到 B 账号的本体、项目或密钥。 |

顶栏右上角有一个**保存状态条**（五态：已保存 / 保存中 / 未保存 / 冲突 / 失败）。工作台**没有保存按钮**——编辑即自动保存（输入停顿约 1 秒后提交）；表单类页面（如编辑对象、编辑共享属性）点"保存"会立即提交。左上角提供**撤销/重做**。

## 4. 本体区菜单

> 侧栏顺序即推荐建设顺序：概览 → 对象建模 → 共享属性 → 业务规则 → 动作定义 → 校验发布。

### 4.1 工作概览 `o-home`

本体的首页与入口集合。

- 顶部工具区：**下载 Excel 模板 / 导入 Excel**（批量填写对象、属性、规则、动作，导入前会检查并预览，同名可选跳过或自动重命名）、**导出配置**（跳转配置迁移并预选当前本体）。
- 本体内容统计：对象类型、共享属性、链接、业务规则、动作的数量。
- 草稿校验提示与"去处理"入口（按问题定位到具体页面/定义）。
- 版本与引用区：显示是否已发布、被哪些项目引用。
- 建设建议：还没建对象时会提示从第一个对象开始。

### 4.2 对象建模 `objects`

本体的核心页面，维护**对象类型**及其全部关联，有两种视图（页签切换）：

| 视图 | 用途 |
| --- | --- |
| **对象列表** | 常规建模：左侧对象列表（搜索/收藏/排序/分页），右侧对象详情。 |
| **本体图谱** | 只读全量视图：把对象、属性、链接、规则、动作及它们的关系画成图，便于整体浏览与定位。图上的**编辑操作一律跳转到源端页面**（双击节点进入对应编辑表单），画布本身只做浏览、布局与定位。 |

对象详情内有四个页签：

- **属性**：把共享属性库中的定义「引用」到本对象（一处修改、所有引用同步），或新建本对象私有的属性；每行可编辑、可「移除引用」（共享定义保留）或「删除属性」（私有），有契约/接口等引用时会阻断并指出位置。
- **链接**：本对象与其他对象的链接（正/反向名称、数量关系），删除链接会从两端同时消失。
- **动作**：可搜索多选，把动作定义关联到本对象；「删除」只移除关联，动作定义与其他对象不受影响。
- **规则**：同上，引用业务规则；移除引用不删除规则定义。

### 4.3 共享属性 `library`

跨对象复用的**属性定义库**：名称、业务定义、数据类型（文本/数值/是或否/时间/数组/结构体/时间序列）、单位、显示格式。

- 「引用到对象」把定义引用给某个对象；对象内引用只读，改共享定义全量同步。
- 「复制为私有」生成对象内独立副本，此后不再跟随共享定义。
- 「删除」有保护：被对象引用或被契约/接口/项目映射直接引用时**阻断**，列出具体依赖并可跳到处理位置；没有引用才允许删除。想保留内容请先在对象里"转为私有"，再删共享定义。
- **修改数据类型或业务定义**（会影响含义的变化）保存时会弹出**影响确认**：展示字段修改前后值 + 受影响对象清单，勾选"已查看"才能提交；确认绑定当时的内容与引用，其他标签页改了原定义或引用变化都会让确认失效，需要重新核对。仅改名称/显示格式不会触发这个弹窗。

### 4.4 业务规则 `rules`

用自然语言维护**通用业务规则**（名称、业务定义、规则内容、输出结果）。对象建模中引用到具体对象；规则库自身提供**安全删除**：有对象关联或契约引用时阻断并给出对象名称与定位入口，无引用时确认后从草稿删除（可撤销）。规则的计算实现与执行在项目侧，不在本页。

### 4.5 动作定义 `actions`

集中维护**共享动作库**：只写名称、业务定义、业务效果三项业务字段。在对象建模里选择哪些对象支持该动作；具体执行方式（接口、参数）由项目侧配置。删除同样受保护：被对象关联或契约引用时阻断并列出依赖；历史格式动作支持只读查看与显式转换为新格式。

### 4.6 本体校验与发布 `o-release`

本体的质检与出厂环节。

- **定义校验**：检查当前草稿的结构完整性（缺名称、悬空引用、类型冲突等），只读检查，不修改草稿，有问题可按条目"去处理"跳到对应页面。
- **发布预检**：与最新发布版本对比，给出**变更分类建议**（兼容 / 破坏性 / 待确认）与理由；破坏性变更会要求升大版本。引用失效时不能人为标为兼容。
- **发布**：确认后生成不可变版本（如 1.0.0），项目只能引用已发布版本。发布不影响已发布的历史版本。

> 提示：**保存草稿允许不完整**（例如刚建了对象还没配属性），但**保存边界会拦截"把已有效的引用改坏"的操作**：例如删掉一个正被契约引用的属性，保存会返回 422 并列出具体引用，草稿内容和版本都不变。历史遗留的失效引用不会锁死你的编辑。

## 5. 项目区菜单

> 项目区服务于"把本体落到具体数据源"。项目必须**先绑定本体的已发布版本**才能做映射；绑定与升级都在项目侧显式操作。

### 5.1 项目概览 `p-home`

项目首页。显示：项目名与标识、**引用的本体与版本**、连接明细（含"凭据已受保护"提示）、当前建设进度与"下一步建议"（直接跳转到待配置的对象/属性）、以及"导出配置"快捷入口（携带当前项目预选）。

### 5.2 数据连接 `connections`

配置项目可用的 **MySQL / Redis 连接**：主机、端口、库名、用户名、TLS 等。密码单独存入本机**受保护存储（vault）**，只写不读回，不出现在项目文件、快照或日志里。

- 「测试连接」是真实网络请求，显示连通结果与错误分类（DNS/认证/超时等）。
- MySQL 连接可「刷新目录」读取表与字段清单（服务端缓存），供对象映射的下拉选择使用。
- 通过测试 ≠ 业务数据已接入；真正的数据映射在"对象映射"页配置。

### 5.3 对象映射 `binding`

项目区的核心页面：先选对象类型，再配置三件事。

1. **实例识别**：这个对象的实例从哪来——数据库表（连接 + 表 + 主键），或项目内**登记实例**（无表对象手填 id 与显示名称）。
2. **属性取值**：每个属性配一个来源，支持——身份表字段直取、**数据库直选表**（任意表 + 匹配条件 + 时间范围，多条件 AND）、**Redis**（GET/HGET + Key 模板）、**函数编排**（引用编排 + 输出 + 输入绑定）、计算规则/函数、登记字段、关联聚合等。时间序列属性会校验时间字段与编码配置。
3. **链接映射**：链接两端各取哪个来源的哪个字段，或按条件选择成员的成员规则。

页面顶部显示当前引用的本体版本（不跟随本体草稿），并在引用失效时给出提示。

### 5.4 函数编排 `f-home`

可复用的**取值函数编排**：把多步计算（Python / SQL / Redis / HTTP / 计算节点）连成一张图，声明输入输出，供对象映射的属性来源引用。

- 支持编排列表（新建、复制、软删除）、画布编辑（拖拽节点、连线、配置节点参数）、**编排配置检查**与**运行测试**（含隔离片段测试）。
- 涉及大模型求值的节点使用设置中心配置的模型（本机不执行任何代码、不联网除外）。
- 编排不依赖选中项目，项目映射中按需引用。

### 5.5 项目校验与发布 `p-release`

项目配置的质检与发布。

- **配置校验**：检查引用版本、对象与属性归属、契约与实现匹配、输入输出绑定等结构完整性；结果按条目列出并可跳转处理。校验通过**不等于**业务数据已验证——那需要到"实例与计算预览"实际取数查看。
- **发布**：通过校验后生成项目版本快照（v1、v2…），已发布快照不可变。

### 5.6 版本引用 `p-upgrade`（从项目概览进入）

**管理引用版本**：本体发布新版本后，在这里比较"当前引用版本 → 新版本"的变化，决定是否切换项目草稿。切换只改项目草稿、按新本体检核映射并列出需要处理的配置；**已发布项目快照保持不变**，切换也不会自动发布。

## 6. 设置中心

左下角齿轮或用户菜单进入；独立于两个工作区。

### 6.1 模型设置 `settings-models`

配置全工作台共用的**大模型接口提供方**（OpenAI 兼容端点、模型名、超时、温度等），供函数编排的 Python / LLM 计算节点使用。API Key **只写不读回**（保存后只显示"已配置"）；支持连通性测试与"设为默认"。默认模型是全局唯一项。

### 6.2 配置迁移 `settings-transfer`

把工作台里的**本体与项目配置打包交接**给另一台工作台或另一个人。

- **导出配置**：勾选本体与相关项目（被项目引用的编排自动纳入，可额外勾选未绑定编排）→「查看导出内容」冻结预览（含版本数、依赖、待补项）→ 下载 ZIP。
- **导入配置**：上传配置包 → 自动预检并预览命名（同名自动加"（导入）""（导入2）"后缀，可改名）→ 确认导入。**每次都创建全新的本体/项目，不覆盖、不合并**；连接密码与 API Key 不在包内，导入后按提示在原位置补填。

> 与之区别：工作概览的"导入 Excel"用于**批量填写本体定义**（对象/属性/规则/动作），不是配置包；两者互不影响。

## 8. 典型使用路径

**从零建设一个本体 → 让项目用起来：**

1. 本体区「＋ 新建」创建本体 → 工作概览（可下载模板批量导入）。
2. 对象建模：建对象类型 → 在共享属性库建属性 → 引用到对象 → 补链接/规则/动作。
3. 本体校验与发布：先定义校验，再发布 → 得到 1.0.0。
4. 项目区创建项目并绑定该本体版本 → 数据连接：配好库并测试 → 刷新目录。
5. 对象映射：逐对象配实例识别 → 属性来源 → 链接映射。
6. 项目校验与发布：校验 → 发布 v1。（如需真实看数，用"实例与计算预览"。）
7. 本体要改时：改本体草稿 → 校验 → 发布新版本 → 在项目「版本引用」里比较并决定是否升级。

**交接给别人：** 设置 → 数据管理 → 配置迁移 → 导出 → 对方导入 → 按提示补填密钥。

## 9. 数据与安全边界（了解即可）

- **本地运行**：服务只绑定 127.0.0.1，不对外网暴露；数据存在本地 SQLite（`data/workbench.sqlite3`）与受保护密钥区，凭据用 AES-GCM 加密、根密钥独立存放。
- **账号隔离**：所有本体/项目/编排/模型配置按登录账号隔离。
- **密码与密钥**：连接密码、API 凭据、模型 Key 只写不读回，永不进入响应、日志、快照或配置包。
- **不可变发布**：本体/项目的已发布版本只读；项目升级引用是显式操作，不会自动跟随草稿。
- **删除保护**：共享属性、规则、动作、属性、链接的删除都先检查引用，阻断时给出具体依赖与跳转位置；本体/项目层不提供一键级联清理。

## 10. 名词速查

| 名词 | 说明 |
| --- | --- |
| 本体（模型） | 一套对象/属性/链接/规则/动作的业务定义，可发布多个版本。 |
| 共享属性 | 可被多个对象复用的属性定义；改一处，全部引用同步。 |
| 私有属性 | 只属于某个对象的属性副本，独立维护。 |
| 稳定 ID | 系统生成的内部标识（`mg:…`），改名不断链；配置请勿手写。 |
| 草稿 / 发布版本 | 编辑期内容 / 不可变的历史版本；项目只引用发布版本。 |
| 实例识别 | 项目里"这个对象的实例从哪来"的配置（数据库表或登记实例）。 |
| 属性来源 | 项目里某个属性的取值方式（字段/直选表/Redis/编排/规则…）。 |
| 函数编排 | 可复用的多步取值函数图，供属性来源引用。 |
| 登记实例 | 无数据库表支撑的对象实例，在项目内手工登记 id 与名称。 |
| 配置包 | 配置迁移导出的 ZIP，用于把本体/项目配置整体交接。 |
