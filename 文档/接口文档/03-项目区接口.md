# 03 · 项目区接口

项目区共 17 个接口：项目资产与草稿、发布、升级预检、数据连接探测、凭据、目录缓存、公式试算、取值预览。
项目区与本体区是**两条独立的数据线**：`/api/save|publish` 只管本体，`/api/project-*` 只管项目。

> **出站请求强制**：所有把项目状态发给后端的请求必须先 `stripCatalogs`（`frontend/src/project/api.ts`），剥除 `bindings.catalogs`。

---

## 1. 项目资产与状态

### 1.1 查询项目清单

```http
GET /api/projects
GET /api/projects?ontology={ontologyId}
```

**筛选契约**（2026-09-18 批次 B 显式化，废除「带任意 query 串即过滤」的隐式语义）：

| 请求 | 行为 |
| --- | --- |
| 不带 `ontology` 参数 | 返回**全部**项目（其他任何参数都不改变范围） |
| `?ontology=<有效本体ID>` | 仅返回该本体的项目 |
| `?ontology=<不存在的ID>` | `404 NOT_FOUND` |
| `?ontology=`（空值） | `400 INVALID_ARGUMENT`（查询全部时应省略该参数） |

**响应** `200`

```json
{ "items": [ { "id": "a1b2c3d4e5f6", "name": "创智项目", "ontologyId": "storage",
               "ontologyVersion": "1.2.0", "hasDraft": true, "latestVersion": "1.3.0" } ] }
```

> `latestVersion` 为该本体最新已发布版本（读取失败时为空串）。
> 前端约定：无筛选时**省略** `ontology` 参数（`project/api.ts` 的 `listProjects` 已如此实现），不要传空字符串。

### 1.2 创建项目

```http
POST /api/projects
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 1–80 字符 |
| `ontology` | string | 否 | 引用的本体标识 |
| `version` | string | 否 | 引用的本体版本（与 `ontology` 成对） |

**响应** `201`

```json
{ "id": "a1b2c3d4e5f6", "name": "创智项目", "ontologyId": "storage", "ontologyVersion": "1.2.0" }
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 名称非法 / 本体或版本不存在 |
| 409 | 同名冲突（未指明本体时全局判重，指明时同本体内判重） |

### 1.3 读取项目草稿

```http
GET /api/project-state?project={projectId}
```

**响应** `200`

```json
{
  "state": { /* ProjectState（bindings.catalogs 由服务端缓存注入） */ },
  "revision": "r-<uuid>",
  "saved": true,
  "project": { "id": "...", "name": "...", "ontologyId": "...", "ontologyVersion": "..." },
  "migrationTodos": [ { "propertyId": "mg:xxx", "ownerType": "mg:yyy", "functionId": "...", "arguments": "..." } ],
  "warning": "引用的本体版本不存在，请先升级到已发布版本"   // 仅版本失效时出现
}
```

| 状态码 | 场景 |
| --- | --- |
| 404 | 项目不存在 |

**说明**：返回时按引用本体版本**自动推导显示名称**（`derive_display_names`），客户端不需维护。

### 1.4 查询项目发布版本

```http
GET /api/project-releases?project={projectId}
```

**响应** `200`

```json
{ "items": [ { "version": "v1", "projectId": "...", "ontologyId": "...", "ontologyVersion": "...",
               "createdAt": "...", "revision": "...", "contentHash": "...", "note": "..." } ] }
```

### 1.5 旧项目配置辅助接口（兼容保留）

```http
GET /api/project-config?ontology={ontologyId}
```

**响应** `200`

```json
{ "project": { "project_id": "chuangzhi", "name": "..." }, "connections": [ { "id": "", "adapter": "", "path": "" } ], "available": true }
```

或 `available:false` + `message`（非 `storage` 本体或无 `chuangzhi` 项目）。

> **状态**：历史兼容接口，当前前端未调用；建议在下轮清理（见 `05` §4 幽灵接口清单）。

## 2. 项目写操作（4 个端点共用一个入口）

服务端 `project_routes.post_project_write` 按路径分派，四个端点共享「规范化状态 → 覆盖服务端目录 → 校验 revision」前置。

### 2.1 保存项目草稿

```http
POST /api/project-save
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `state` | ProjectState | 是 | 完整项目状态（含 `projectId`） |
| `revision` | string | 是 | 并发基线 |

**响应** `200`

```json
{ "revision": "r-<uuid>" }
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 项目标识非法 / 状态结构非法 |
| 409 | revision 过期（带 `currentRevision`） |
| 500 | 草稿保存失败（存储层错误，绝不返回成功） |

**说明**：保存**不要求**绑定本体版本，也不做配置校验（配置校验是独立接口）。

### 2.2 项目配置校验

```http
POST /api/project-validate
```

请求体：`{ state, revision }`（`revision` 仅透传，本接口不校验版本）

**响应** `200`

```json
{ "errors": [], "warnings": [],
  "items": [ { "kind": "objectBinding", "id": "mg:xxx", "name": "...", "status": "...", "issues": ["..."] } ] }
```

未绑定本体版本时返回 `200` + 单条 `reference` item（视为「未配置」而非错误）。

> 校验规则的权威实现在 `workbench/project_validation.py`；**改规则必须同步更新金样**（`tests/make_validation_golden.py` + `tests/test_validation_split.py`）。

### 2.3 发布项目

```http
POST /api/project-publish
```

请求体：`{ state, revision }`

**响应** `200`

```json
{ "revision": "r-<uuid>", "version": "v2" }
```

| 状态码 | 场景 |
| --- | --- |
| 409 | revision 过期（带 `currentRevision`） |
| 422 | 未绑定本体版本；或配置校验未通过（`{"error": "...", "report": <ValidationReport>}`） |

**约束**：持全局写锁；草稿快照 + CAS head + 发布快照 + 发布记录 + 版本引用**单事务**。

### 2.4 本体版本升级预检

```http
POST /api/project-upgrade-check
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `state` | ProjectState | 是 | 当前项目状态 |
| `targetVersion` | string | 是 | 目标本体版本 |

**响应** `200`

```json
{ "classification": "breaking", "reasons": [], "impacts": [], "blocking": [] }
```

（结构见 `01` §5.4）

| 状态码 | 场景 |
| --- | --- |
| 422 | 项目尚未绑定本体版本（`{"error": "..."}`） |

**说明**：只读预检，**不自动升级**；前端 `ReferenceNotice` 只做对比展示，升级由用户显式触发。

## 3. 数据连接

### 3.1 连接连通性测试

```http
POST /api/connection-test
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `projectId` | string | 是 | 项目标识 |
| `connection` | ConnectionConfig | 是 | 连接配置 |
| `password` | string | 否 | 本次测试用密码（不落盘） |
| `useSaved` | boolean | 否 | true 且 `connection.id` 存在时，从 vault 读取已保存密码 |

**响应** `200`

```json
{ "ok": true, "category": "ok",
  "message": "连接成功：服务可达、认证与基本命令可用（不代表表权限或业务数据已验证）", "latencyMs": 12 }
```

失败形态（HTTP 仍为 200，业务结果在 `ok` 字段）：

```json
{ "ok": false, "category": "auth", "message": "认证失败：请核对用户名、密码或受保护凭据是否有效", "latencyMs": 30 }
```

`category` 取值见 `01` §6。**约束**：真实网络探测，**绝不持全局写锁**；只执行 `SELECT 1` / `PING`。

### 3.2 读取表结构目录（临时凭据）

```http
POST /api/connection-catalog
```

请求体：同 3.1

**响应** `200`

```json
{ "ok": true, "database": "db_name",
  "tables": [ { "name": "t_device", "kind": "table", "fields": [ { "name": "id", "dataType": "bigint", "key": "pri", "comment": "" } ] } ],
  "refreshedAt": "2026-09-18T05:00:00+00:00",
  "message": "已读取 12 张表／视图的结构目录（不含数据内容）" }
```

Redis 连接返回 `{"ok": false, "category": "config", "message": "Redis 连接没有表结构目录；请选择 MySQL 连接"}`。

### 3.3 刷新并持久化目录缓存

```http
POST /api/catalog-refresh
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `projectId` | string | 是 | — |
| `connectionId` | string | 是 | 项目内已保存的连接 id |

**响应** `200` —— 同 3.2 的目录结果

| 状态码 | 场景 |
| --- | --- |
| 400 | 缺少连接标识 / 项目中不存在该连接 / 连接未配置引擎 |
| 404 | 项目不存在 |

**约束**：从已保存连接 + vault 凭据读取；**迟到结果保护**：探测前后比对连接配置指纹，不一致则丢弃结果，不落缓存。目录缓存在服务端，**不进草稿与快照**。

### 3.4 连接密码存取

```http
POST /api/connection-secret
```

请求体：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `projectId` | string | — |
| `connectionId` | string | — |
| `action` | `set` \| `clear` | — |
| `secret` | string | `set` 时必填 |

**响应** `200`

```json
{ "saved": true }
```
或
```json
{ "cleared": true }
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 项目标识非法 / action 无效 / 参数缺失 |

**安全红线**：密码只写 vault，**永不回传**、不进项目 YAML/快照/日志。

## 4. API 凭据

### 4.1 查询凭据清单

```http
GET /api/api-credentials?project={projectId}
```

**响应** `200`

```json
{ "items": [ { "id": "cred-xxx", "name": "生产接口" } ] }
```

> 只返回 `id`/`name` 元数据，**绝不返回密钥**。

| 状态码 | 场景 |
| --- | --- |
| 400 | 项目标识非法 |
| 404 | 项目不存在 |

### 4.2 登记 / 清除凭据

```http
POST /api/api-credential
```

请求体：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `projectId` | string | — |
| `action` | `set` \| `clear` | — |
| `credentialId` | string | `set` 时为空表示新建；`clear` 时必填 |
| `name` | string | `set` 时必填 |
| `secret` | string | `set` 时必填 |

**响应** `200`

```json
{ "saved": true, "credential": { "id": "cred-xxx", "name": "生产接口" } }
```
或
```json
{ "cleared": true }
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 动作无效 / 参数缺失 / 标识非法 |
| 404 | 项目不存在 |

**说明**：与连接密码 vault 是**独立命名空间**（`workbench/api_credentials`），供 HTTP 节点 / 动作接口引用认证；密钥只写不读回。

## 5. 公式试算与取值预览

### 5.1 计算函数公式校验 / 试算

```http
POST /api/calc-eval
```

请求体：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `expression` | string | 公式，语法 `calc-expression-1` |
| `inputs` | array | `[{ "id": "<稳定id>", "type": "number\|string\|boolean", "value": any }]`，最多 50 项 |
| `outputType` | string | `number` \| `string` \| `boolean` |
| `validateOnly` | boolean | true 时仅静态校验 |

**响应** `200`

```json
{ "ok": true, "value": 12.5 }
```
或
```json
{ "ok": false, "error": "参数 p1 不存在（可能已被删除或改名）" }
```

| 状态码 | 场景 |
| --- | --- |
| 200 | 业务失败也用 200 + `ok:false`（纯只读计算，不持锁、不写草稿） |

**公式语法**：字面量（数值 / `'文本'` / true / false）、`{参数标识}`、`+ - * /`、比较 `= != < <= > >=`、白名单函数 `IF/MIN/MAX/ABS/ROUND/ERROR`。禁止 SQL、属性访问、循环、`eval`；长度 ≤ 500、嵌套 ≤ 20、节点 ≤ 200。

### 5.2 项目属性取值预览（受限只读）

```http
POST /api/project-property-preview
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `projectId` | string | 是 | — |
| `revision` | string | 是 | 客户端当前项目 revision（**必填**，防读到过期配置） |
| `objectType` | string | 是 | 对象类型 |
| `instanceId` | string | 是 | 已登记实例 id |
| `property` | string \| null | 是 | 属性名；**空串 = 仅成员预览** |

**响应** `200`

```json
{
  "status": "ok",                 // ok | empty | incomplete | error
  "value": 12.5,
  "memberCount": 3,
  "missingCount": 0,
  "membersPreview": [ { "id": "...", "label": "...", "value": 4.2 } ],
  "truncated": false,
  "evaluatedAt": "2026-09-18T05:00:00+00:00",
  "message": "..."
}
```

> 冻结契约：**全部字段恒存在**（无值时为默认值）。

| 状态码 | 场景 |
| --- | --- |
| 400 | 参数缺失/非法、项目不存在（协议层错误） |
| 409 | revision 过期（带 `currentRevision`） |

**约束**：短锁读取已保存草稿并核对 revision，**联网查询期间不持锁**；仅支持「登记信息」与「关联聚合（sum）」两类来源，其他来源返回 `status:'error'` + 说明。
