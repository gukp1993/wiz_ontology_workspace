# 02 · 本体区接口

本体区共 23 个接口。本体资产 / 草稿 / 版本 / 发布 / 校验 / 预览 / 探索 / 导出与恢复。

> **通用前置**（GET 除 `/api/ontologies` 外全部适用）：服务端先按 `ontology` 参数定位工作区，标识非法即返回 404（本体不存在）或 400（标识格式无效）。缺省 `ontology=storage`。
> **通用请求体**（POST 除创建/导出外）：`{ "state": <OntologyState>, ... }`，其中 `state.ontology` 为 schema 形态，服务端 `decode_state` 解码。

---

## 1. 本体资产

### 1.1 查询本体清单

```http
GET /api/ontologies
```

**响应** `200`

```json
{ "items": [ { "id": "storage", "name": "储能本体" } ], "defaultId": "storage" }
```

> 默认本体 `storage` 仅在已持有草稿后出现（资产行随首次保存建立）。

### 1.2 创建本体

```http
POST /api/ontologies
Content-Type: application/json
```

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 1–80 字符 |

**响应** `201`

```json
{ "id": "<uuid>", "name": "新本体" }
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 名称缺失或超长 |
| 409 | 已存在同名本体（`DuplicateName`） |

**约束**：持全局写锁；创建时即写入空白草稿状态。

## 2. 草稿读写

### 2.1 读取本体草稿

```http
GET /api/state?ontology={ontologyId}
```

| Query | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ontology` | 否 | `storage` | 本体标识（`storage` 或规范 UUID） |

**响应** `200`

```json
{
  "state": { /* OntologyState（encode_state 后，ontology 为 schema 形态） */ },
  "revision": "r-<uuid>",
  "saved": true,
  "ontology": { "id": "storage", "name": "储能本体" },
  "latestVersion": "1.2.0"
}
```

- `saved`：是否已存在草稿（false 表示空白状态）。
- `revision`：无草稿时为「空白状态内容 hash」一次性基线。

### 2.2 保存本体草稿

```http
POST /api/save
```

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `state` | OntologyState | 是 | 完整状态（含 `workspaceId`） |
| `revision` | string | 是 | 客户端并发基线 |

**响应** `200`

```json
{ "revision": "r-<uuid>", "errors": ["..."], "ontology": { "id": "...", "name": "..." } }
```

- `errors` 为**校验提示**，非空**不阻断保存**（草稿允许带错保存；发布才阻断）。

| 状态码 | 场景 |
| --- | --- |
| 400 | state 结构非法 |
| 409 | revision 过期，响应带 `currentRevision` |
| 503 | 存储不可用 |

**约束**：持全局写锁；CAS 原子提交。

### 2.3 从历史快照恢复

```http
POST /api/restore
```

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `state` | OntologyState | 是 | 当前客户端状态（用于定位本体） |
| `revision` | string | 是 | 并发基线 |
| `release` | string | 是 | 快照文件名（`*.zip`，由 `GET /api/releases` 返回，不接受路径分隔符） |

**响应** `200`

```json
{
  "revision": "r-<uuid>",
  "state": { /* 恢复后的 OntologyState */ },
  "ontology": { "id": "...", "name": "..." },
  "errors": [],
  "backup": "20260918T050000123456Z-r-<8位>.json",
  "release": "xxx.zip",
  "note": "快照中的项目配置未恢复到项目草稿；项目数据由项目绑定区独立维护。"
}
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 快照名非法、快照不属于当前本体、缺少本体定义文件 |
| 409 | revision 过期（带 `currentRevision`） |

**约束**：持全局写锁；恢复前自动写一份当前状态备份（附件表）；**只恢复本体部分**，项目配置不回灌。

## 3. 版本与发布

### 3.1 查询版本清单

```http
GET /api/versions?ontology={ontologyId}
```

**响应** `200`

```json
{ "items": [ { "version": "1.2.0", "changeType": "compatible", "changeNote": "", "reviewer": "",
               "createdAt": "...", "revision": "...", "parentVersion": "1.1.0", "reasons": [] } ] }
```

### 3.2 读取指定版本状态

```http
GET /api/version-state?ontology={ontologyId}&version={version}
```

| Query | 必填 | 说明 |
| --- | --- | --- |
| `version` | 是 | 语义化版本号，如 `1.2.0` |

**响应** `200`

```json
{ "state": { /* 该版本的 OntologyState */ }, "version": "1.2.0" }
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 缺少 `version` |
| 404 | 版本不存在 |

### 3.3 查询可恢复快照清单

```http
GET /api/releases?ontology={ontologyId}
```

**响应** `200` —— **直接返回字符串数组**（历史遗留形态，与其他接口的 `{"items":[]}` 不一致，演进项见 `05` §2）

```json
["20260918T050000123456Z.zip", "20260917T120000000000Z.zip"]
```

### 3.4 发布预检（变更分类建议）

```http
POST /api/publish-check
```

**请求体**：`{ "state": <OntologyState> }`

**响应** `200`

```json
{
  "suggested": "compatible",
  "reasons": [ { "severity": "compatible", "area": "objectTypes", "id": "mg:xxx", "text": "新增对象类型 mg:xxx" } ],
  "latest": "1.2.0",
  "canCompatible": true
}
```

- `suggested`：`initial`（首个版本）/ `compatible` / `breaking` / `pending`（需人工确认）。

### 3.5 发布本体版本

```http
POST /api/publish
```

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `state` | OntologyState | 是 | 待发布状态 |
| `revision` | string | 是 | 并发基线 |
| `changeType` | string | 条件 | `compatible` / `breaking`；`suggested=pending` 时必填 |
| `changeNote` | string | 否 | 变更说明（缺省取 `workflow.release.note`） |
| `reviewer` | string | 否 | 审核人 |
| `requestId` | string | 否 | 幂等键 |

**响应** `200`

```json
{ "revision": "r-<uuid>", "errors": [], "version": "1.3.0",
  "changeType": "compatible", "reasons": [], "ontology": { "id": "...", "name": "..." },
  "idempotentReplay": true }
```

| 状态码 | 场景 |
| --- | --- |
| 409 | revision 过期（带 `currentRevision`）；或 `requestId` 已被不同内容使用 |
| 422 | 校验未通过（响应体为 `{"errors": [...]}`）；或破坏性变化被标为兼容；或存在待确认变更未选类型 |

**约束**：持全局写锁；草稿快照 + head CAS + 发布快照 + 发布记录**单事务**；版本号按数值递增（breaking → 大版本 +1，否则次版本 +1）；`requestId` 幂等回放。
**规则**：引用失效的结构变化**禁止**人工改标为兼容。

## 4. 校验与预览

### 4.1 本体配置校验

```http
POST /api/validate
```

请求体：`{ "state": <OntologyState> }`

**响应** `200`

```json
{ "errors": ["本体中存在重复标识", "mg:xxx 缺少名称"] }
```

**只读**，不写盘、不持锁。

### 4.2 发布就绪度检查

```http
POST /api/workflow-check
```

请求体：`{ "state": <OntologyState> }`

**响应** `200`

```json
{ "errors": [], "warnings": ["xxx：定义已记录，尚无匹配的本地实现"],
  "can_publish": true, "counts": { "functions": 3, "actions": 1, "interfaces": 0 } }
```

### 4.3 演示执行预览

```http
POST /api/preview
```

请求体：`{ "state": <OntologyState>, "projectState": <ProjectState>（可选） }`

**响应** `200`

```json
{ "errors": [], "objects": [ /* 实例 */ ], "result": { /* 执行结果 */ } }
```

或数据未就绪：

```json
{ "errors": ["当前本体尚未配置可用的实例数据与计算实现；请先完成数据接入。"], "objects": [], "available": false }
```

### 4.4 演示对象列表

```http
POST /api/demo-objects
```

请求体：`{ "state", "projectState"(可选) }`

**响应** `200`

```json
{ "objects": [ { "id": "...", "type": "...", "display_name": "...", "properties": {}, "parents": {} } ],
  "bindings": { "unsupportedSources": [ { "objectType": "", "property": "", "kind": "computed" } ] } }
```

| 状态码 | 场景 |
| --- | --- |
| 422 | 演示数据不可用（`{"error": "...", "available": false}`） |

> 演示引擎只接受**直接字段映射**（字符串值）；`computed` / `database` / `redis` / `registered` 等来源被过滤并上报 `unsupportedSources`。

### 4.5 计算函数试算

```http
POST /api/function-preview
```

请求体：

| 字段 | 说明 |
| --- | --- |
| `state` / `projectState` | 同 4.3 |
| `definitionId` | 待试算的函数定义 id |
| `parameters` | `{ "object_id": "...", "at": "2026-09-08T10:00:00+08:00" }` |

**响应** `200`

```json
{ "result": { "value": 12.5 }, "applied": false }
```

| 状态码 | 场景 |
| --- | --- |
| 422 | 数据未就绪 / 定义校验失败 / 对象不存在或类型不匹配 / 输出值不满足属性取值约束 |

### 4.6 动作试运行

```http
POST /api/action-preview
```

请求体：`{ state, projectState, definitionId, parameters }`

**响应** `200`

```json
{ "dry_run": true, "object": "xxx", "before": "...", "after": "...",
  "relation": "belongsToSystem", "applied": false }
```

| 状态码 | 场景 |
| --- | --- |
| 422 | 数据未就绪 / 定义错误（`{"errors": [...]}`） |

### 4.7 值类型取值校验

```http
POST /api/value-type-check
```

请求体：`{ state, valueTypeId, sample }`

**响应** `200`

```json
{ "valid": false, "errors": ["取值超出范围"] }
```

| 状态码 | 场景 |
| --- | --- |
| 404 | 值类型不存在 |

### 4.8 显示格式预览

```http
POST /api/format-preview
```

请求体：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | any | 输入样本（序列化 ≤ 20000 字符） |
| `dataType` | string | 默认 `string` |
| `config` | object | 格式定义（≤ 20000 字符）；`mode=natural` 走大模型，需配置 `FORMAT_LLM_URL`/`FORMAT_LLM_MODEL` |

**响应** `200`

```json
{ "formatted": "12.5 kWh" }
```

| 状态码 | 场景 |
| --- | --- |
| 400 | 格式定义非对象 / 样本过大 / 未配置大模型 |

> 空值直接返回空值占位文本，任何模式都不发模型请求。

## 6. 定义索引与存储状态

### 6.1 只读定义查询

```http
GET /api/model-definitions?ontology={id}&version={v}&kind={k}&owner={o}&q={kw}&limit={n}&cursor={offset}
```

| Query | 默认 | 说明 |
| --- | --- | --- |
| `ontology` | `storage` | 本体标识 |
| `version` | 当前草稿快照 | 指定已发布版本 |
| `kind` | 全部 | 定义类型过滤 |
| `owner` | 全部 | 所属对象过滤 |
| `q` | — | 关键字 |
| `limit` | 50 | 1–100 |
| `cursor` | 0 | 偏移量 |

**响应** `200`

```json
{ "items": [ { "kind": "objectTypes", "id": "mg:xxx", "name": "...", "owner": "..." } ],
  "cursor": 50, "snapshot": "<snapshotId>", "version": null }
```

- 无下一页时 `cursor` 为 `null`；**快照切换后游标失效**。
- 索引缺失时自动按完整文档重建投影（不写快照/head）。

| 状态码 | 场景 |
| --- | --- |
| 400 | 分页参数无效 |
| 404 | 指定版本不存在 |

### 6.2 存储健康状态

```http
GET /api/storage-status
```

**响应** `200`

```json
{ "ready": true, "schemaVersion": "20260918-01", "backend": "sqlite" }
```

> 仅返回就绪状态、schema 版本与后端类型，**绝不含 DSN 与密钥**。

## 7. 导出

### 7.1 导出模型快照 ZIP

```http
POST /api/export
Content-Type: application/json
```

请求体：`{ "state": <OntologyState> }`

**响应** `200`

- `Content-Type: application/zip`
- `Content-Disposition: attachment; filename=ontology-model.zip`
- 包内：`manifest.json`、`ontology.json`、`workflow.json`、`metrics.yaml`、`rules.yaml`、`layout.json`（可选 `learning.json`、`imports/source-graph.json`）

**约束**：**二进制专用通道**（server.py 内特判，不走 JSON 响应）；前端必须用 `postBlob`，不得按 JSON 解析。
