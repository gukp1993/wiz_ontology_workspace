# 旧图谱编辑器迁移说明

已将旧项目 frontend 复制到当前项目，保留 Vue 3、Cytoscape、Vite、依赖锁文件与图样式、节点尺寸计算；编辑入口改造为对接当前本体工作台接口。

## 保留与适配

- `frontend/src/shared/graphStyle.js`、`layout.js`：复用旧项目画布样式与尺寸逻辑。
- `frontend/src/graphAdapter.js`：本体→Cytoscape转换，及从旧 EditorView 的 applyGraphState 适配而来的原地增删更新。
- `frontend/src/App.vue`：精简工作台；复用旧编辑流程，包括节点拖动、两端点击建关系、快照撤销重做、搜索、自动布局、一跳查看。
- 当前Python后端与草稿接口继续使用，已有草稿可加载。

## 删除范围

复制后的旧登录、路由、MCP运维、Excel导入、旧jsonId导入导出、旧多图谱版本弹窗及对应前端模块已移除。旧后端未复制，以免引入另一套存储和登录系统。当前最早的手写SVG前端 `workbench/static` 已被构建后的Vue前端替代。

`vue-router` 依赖暂留在复制的清单与锁文件中，未再使用；没有为此重装或无关升级依赖。

## 数据区别

对象类型保留稳定的 `mg:...` ID，不按顺序重新编号。属性在节点详情中编辑。关系以 OWL ObjectProperty 表达，起终点对应 domain/range。

草稿内的 `layout` 是展示数据；发布ZIP单独保存 `layout.json`。拖动不会改变JSON-LD定义。发布仍是快照，不会自动激活生产配置。

## 启动与构建

```bash
cd frontend
npm run build
cd ..
python3 -m workbench.server
```

打开 http://127.0.0.1:8765/ 。首次没有依赖时在frontend目录运行 `npm ci`。

## 使用

- 拖动节点；滚轮缩放；空白处拖动平移。
- 点击“创建关系”，依次点击两个类型，再填标识与名称。
- 点击节点或连线，在右侧编辑。
- 工具栏撤销/重做；快捷键 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z、Cmd/Ctrl+S。
- “自动布局”整理，可撤销；“一跳关系”突出选中类型的直接邻居，“全图”恢复。
- 搜索名称或ID，回车聚焦结果。
- 草稿保存包括布局，刷新后恢复；布局变更也会标记未保存。

## 画布交互补齐

对照旧 EditorView 的按键表补齐：F聚焦、Shift+F缩小、Delete/Backspace批量删除、Esc取消、?说明弹窗、搜索框Tab循环，保留Ctrl/⌘+Z、Shift+Z、S。输入框、弹窗、非图页面与输入法组合状态有独立保护。

画布默认占满，目录与详情按钮按需打开；双击节点展开详情；恢复旧版滚轮灵敏度与0.1—4缩放范围，增加只读预览、批量删除及一跳开关。恢复接近旧版的浅绿点阵画布、工具分组与绿色编辑操作按钮。保留本体工作台的整体导航。
