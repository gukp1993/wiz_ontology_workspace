## 强制约束

- 示例 park_id_column 仅占位；不得当作真实字段写入业务数据。
- 不自动把整张设备表求和；不自动添加 COALESCE 或单位换算。
- 不自动将历史 aggregate 配置转换成 SQL，不删除已有用户配置。
- 只接受单条 SELECT 模板；多步、动态表名继续使用已有规则库。
- 参数识别避开 SQL 字符串、注释、反引号，保留仍存在的绑定；0/false/明确空字符串不能视作未填。
- 不引入 SQL 执行接口、LLM 执行、跨库编排、大型编辑器依赖。
- 不将“配置检查通过”写成“SQL 验证成功”。
