# 项目映射与数据连接需求说明

日期：2026-09-14  
状态：开发交接版。范围内的交互方向已由用户确认，技术细则中的“建议”由开发结合代码落实。  
原型：[项目映射交互原型](../prototypes/项目映射交互原型.html)  
开发指令：[GLM 开发指令](../交付物/GLM开发指令_项目映射_20260914.md)

## 1. 目标与边界

在现有工作台上改进项目映射，让实施人员明确每个对象、属性和链接的数据来源，而不把项目表名、Redis Key 或函数实现写入通用本体。

保留“本体空间／项目空间”与两条独立的草稿、发布线。继续使用 Vue3、TypeScript、Python HTTP 服务，以及当前管理后台视觉风格和 AppSelect 下拉组件。

本轮只修改项目层。实际数据接入范围：真实连接测试、数据库表／字段元数据读取；属性取值、跨来源联查、Redis 业务 Key 查询和函数执行仍是配置管理，不承诺上线执行。

不增加账号权限系统，不重做本体属性和计算契约。时间序列属性、历史序列接入和 ES 直接查询不在本轮实施范围；数据结构可以扩展，但不得放出不能工作的操作入口。

## 2. 用户已经确认的规则

1. 数据来源中的数据连接使用下拉，只能选择当前项目已配置连接。
2. 增加数据连接配置页，配置后支持真实测试连通性。
3. 一个对象可以关联多个数据来源，包括多张数据库表和 Redis；补充来源可为零个、一个或多个。
4. 表来源不限定为一对一；允许同一实例匹配多条记录，但取值规则必须明确。
5. 每个属性只保存一种生效的取值方式：数据库字段、Redis 查询或函数结果。不是为同一个单值属性同时配置多套候选取法。
6. 链接映射的起点和终点都从各自对象已配置的表及字段中下拉选择，不手填表名和字段名。
7. 原型中的单位、扩展表和采样函数仅为例子，不得自动写入真实本体和项目。

Redis 与函数在用户界面保留两种取值方式。内部可以共用参数绑定结构，但不能让简单 Redis 取值强制创建本体计算契约。

## 3. 页面组织

项目空间新增“数据连接配置”入口。对象绑定仍使用左侧对象列表、右侧详情，主要页签为：

- 对象数据来源：登记实例识别来源及补充来源。
- 属性来源：列出本体属性及当前唯一取值方式，逐项配置。
- 链接映射：选择两端已配置表和字段建立关联。

“全部计算实现”、项目校验和项目版本管理继续保留。来源配置与函数实现共享当前项目上下文，不在页面之间复制数据。

## 4. 数据连接配置

### 4.1 连接表单

首期建议正式支持 MySQL 与 Redis，满足现有 SQL DDL 和业务需求。不要把 MySQL 适配器显示为支持所有数据库。其他引擎后续逐个增加。

| 内容 | MySQL | Redis |
| --- | --- | --- |
| 连接名称 | 必填，当前项目内唯一 | 同左 |
| 主机与端口 | 必填；端口默认 3306，可修改 | 必填；端口默认 6379，可修改 |
| 数据范围 | 数据库名称 | DB 索引，默认 0 |
| 认证 | 用户名、密码或已有受保护凭据引用 | 用户名按需、密码或受保护凭据引用 |
| TLS | 按需配置并校验证书 | 同左 |

连接 ID 自动生成，引用一律使用 ID。界面显示名称，改名不使引用失效。被数据来源或实现使用的连接禁止直接删除或改变引擎类型，需显示引用位置。

密码输入为写入型，不从 API 回传原文。已有密码显示“已配置”；保留、替换、清除需有明确操作，空输入不应误删原密码。凭据不进入 connections.yaml、发布快照、日志、URL、前端持久存储或诊断回显；项目配置仅保存受保护引用。

### 4.2 测试连接

新建和编辑时都可以点击“测试连接”，使用当前表单配置，无需先发布项目。测试成功不自动保存表单，测试失败也允许保存未验证的草稿。

状态：未测试 → 测试中 → 连接成功／连接失败。连接参数或凭据修改后，旧结果失效；仅改显示名称不必使技术测试结果失效。切换连接或再次发起测试时，较旧响应不能覆盖新状态。

| 引擎 | 测试动作 | 成功能证明什么 |
| --- | --- | --- |
| MySQL | 建立连接、认证、选择目标数据库，执行只读 SELECT 1 | 服务连接、认证和基本查询可用 |
| Redis | 建立连接、认证、选择 DB，执行 PING | 服务连接、认证和基本命令可用 |

失败应区分地址解析失败、连接拒绝、超时、认证失败、数据库不存在、权限不足、TLS 失败、驱动未安装；显示用户能处理的原因，不泄露连接密钥或堆栈。

建议总超时 5～10 秒，重复点击期间禁用按钮；超时关闭连接，不无限重试。网络探测不能持有全局写锁阻塞其他保存；需要持久化结果时再短暂加锁并校验修订。

仅开放指定驱动的连接测试，不执行用户提交的任意 SQL、脚本或命令。真实测试接口沿用现有 Origin、POST 白名单、请求大小限制等保护。项目通常访问内网数据库，不应一刀切禁止私网地址。

“连接成功”不等于业务数据接入成功，不证明所有表可读、主键唯一、关联基数正确、Redis Key 存在或函数可执行。

### 4.3 表与字段目录

数据库来源选择连接后，支持读取该连接权限范围内的表／视图及字段目录。字段目录至少包含名称、数据类型、主键／唯一约束信息（可取得时）和备注。

提供“刷新表结构”。读取失败保留旧选择并标明目录未刷新，不能静默清空映射。已选字段删除或类型变化应在校验中提示。

链接页只用来源所属表的字段目录。缺少目录时提示“先刷新表结构”，不退回手填。原型使用硬编码目录仅为展示，正式实现禁止沿用示例字段作为真实元数据。

## 5. 对象数据来源

### 5.1 实例识别与补充来源

对象类型描述业务概念。项目中的实例来源负责确定“有哪些实例”和“如何识别”，不是规定所有属性必须来自一张表。

首期继续保留一个数据库表／视图作为实例识别来源，以兼容现有对象表、主键和标题属性配置。其他来源可独立添加和删除，Redis 也作为该对象的补充来源登记。

| 来源 | 配置内容 |
| --- | --- |
| 实例识别来源 | 名称、数据库连接、表／视图、主键、标题属性 |
| 数据库补充来源 | 名称、数据库连接、表／视图、与已识别实例的匹配字段、匹配数量 |
| Redis 来源 | 名称、Redis 连接；具体 Key 在属性查询配置中维护 |

首期匹配从实例识别来源直连补充表；多层联表、多个实例来源的合并去重不在本轮。跨连接来源可以登记，但跨库联合执行并未实现，页面与校验须明确标记，不伪装成已验证联查。

### 5.2 多表与多记录

例如台账 `m_storage_cluster_phase.id` 对应扩展表 `cluster_ext.cluster_id`，或对应采样表 `cluster_power_sample.cluster_id`。

- 零或一条：无记录按属性缺失策略处理；超过一条视为不满足配置约定，不可任选一条。
- 零或多条：来源合法，但普通单值属性需要指定取最新、求和或求平均等取值规则。
- 取最新需指定排序时间字段；时间相同时需配置唯一的次级排序字段或明确报错，不依赖不稳定顺序。
- 汇总只适用于可汇总数值，且必须符合本体属性的业务口径；把额定功率任意求和不能仅因 SQL 可执行就算业务正确。
- 一对多的业务实体，如订单与订单明细，仍应按业务需要使用对象与链接，不能因配置了补充来源就把实体自动合并。

来源被属性、链接或输入绑定引用时，删除须先处理引用。改变来源类型或基数时检查已有映射，不自动丢弃原配置。

## 6. 属性来源：每个属性一份配置

列表显示属性名称、类型、当前来源方式、简要路径、配置状态及“配置”按钮。详情中单选一种方式，只展示对应字段。

编辑使用局部草稿。切换方式并保存后，以新结构整体替换旧来源；取消保留原配置。不能把旧 Redis 配置藏在函数配置下仍作为有效候选执行。

### 6.1 数据库字段

选择当前对象已配置的数据库来源，再选择字段。额定功率可以绑定实例来源的 `rated_power`，也可以绑定其他表的相应字段。

补充来源直接复用对象级匹配关系，无需每个属性重复填联表条件。一对多来源的多行处理和缺失处理属于该属性的取值配置。

### 6.2 Redis 直接查询

| 配置项 | SOC 示例 |
| --- | --- |
| Redis 来源 | 储能簇实时测点 |
| 读取方式 | GET；也支持 HGET |
| Key 模板 | m_storage_cluster-{id}-soc |
| 参数绑定 | id ← 当前储能簇的实例来源主键 |
| Hash 字段 | 仅 HGET 必填 |
| 结果转换 | 按目标属性类型选择可支持的转换 |
| 未找到或转换失败 | 明确返回无数据或错误；不静默变为 0 |

模板是全体实例共用的项目规则。当前实例主键为 123 时，Key 展开为 `m_storage_cluster-123-soc`，不逐实例配置。

每个占位符都必须有结构化绑定。可选择实例主键或当前对象已映射属性，引用使用稳定来源／属性 ID。不要把字符串 {id} 未加说明地当作可执行规则。

“预览 Key”只做本地模板展开，不读取 Redis。若以后增加真实取值测试，应作为独立能力明确说明，本轮只实现连接 PING 测试。

### 6.3 函数结果

选择已有项目计算实现、输出和契约所需输入。储能簇输入可绑定当前对象；时间参数来自调用上下文；其他计算输出按现有规则引用并检查循环依赖。

函数规则仍在独立实现页维护。属性页面只引用，不复制第二份规则，也不将源主键偷偷替换成对象引用或反之。

字段映射、Redis 查询和函数结果都是来源方式；普通属性与时间序列是返回数据形态，不能混为一套枚举。本轮原型仅演示普通单值的取值配置。

## 7. 链接映射：两端全下拉

链接类型及起点、终点由本体引用确定。项目页面填写：

1. 起点表：只能选起点对象已经配置的数据库来源。
2. 起点字段：只能选该来源表的已登记字段。
3. 终点表：只能选终点对象已经配置的数据库来源。
4. 终点字段：只能选该来源表的已登记字段。

不提供表名／字段名自由输入。更换表清空旧字段，提示重新选择。无法选择时引导到对应对象的数据来源配置或字段目录刷新。

示例：储能簇扩展来源 `cluster_ext.company` 关联单位实例来源 `m_company.id`。双方来源都可能是补充表，因此系统必须保留两端来源与各自实例身份的路径，不只保存表名字符串。

本体链接数量关系约束匹配结果：多对一／一对一的目标匹配键需要可确认的唯一性；一对多／多对多可匹配多个目标实例，但要按目标实例标识去重。未知唯一性标记待验证，不能假称验证通过。当前不能表达或执行的关系应明确提示，不静默挑第一条。

## 8. 数据结构与现有代码衔接

遵循仓库 AGENTS.md、V3 设计方案、实施说明。以下为结构原则，不要求生搬原型中的变量名：

| 数据 | 存放位置 |
| --- | --- |
| 连接定义（不含凭据原文） | 项目 connections.yaml |
| 对象来源、匹配关系、字段映射、Redis 属性查询、链接映射 | 项目 bindings.yaml |
| 函数实现、输入绑定、输出声明 | 项目 implementations.yaml |
| 项目参数 | 项目 parameters.yaml |
| 项目身份及本体版本引用 | 项目 project.yaml |

来源使用稳定 ID；字段绑定同时记录所属来源 ID，避免不同表相同字段名碰撞。字段重命名需刷新并重新确认，不用字段标签替代关联键。

兼容现有顶层 table／connection／primary_key、字符串属性字段、kind=computed、related_sources 和原链接 column。旧内容加载后可以通过内存适配进入新 UI；旧发布快照不可改写，迁移保存只产生新的项目草稿修订。

现有前端 ProjectBinding.vue 可按职责拆出连接编辑、来源编辑、属性取值和链接映射组件。项目校验主要在 projects.py；新增驱动与元数据读取宜独立成后端模块，避免让 server.py 承担全部逻辑。

若确需修改本体协议层，model_format.py 与 modelFormat.ts 必须镜像修改；本轮优先不触碰本体定义，不能为项目来源增加业务属性。

## 9. 验收标准

### 连接与元数据

- 新建 MySQL／Redis 连接后，对象来源下拉能选择；不显示其他项目的连接。
- 正确连接真实测试成功；错误密码、不可达端口、超时产生可区分错误。
- 改配置后旧结果失效；旧请求晚返回不覆盖新配置状态。
- 测试操作不写业务表、不更改 Redis Key、不持有全局锁等待网络。
- 表／字段下拉来自真实元数据；不足权限提示清楚，刷新失败不丢旧映射。
- 凭据不进入导出快照和日志；密码编辑不会误清除旧凭据。

### 来源与属性

- 对象只有实例来源也能保存；可添加多个补充表和 Redis 来源。
- 单值属性能分别配置数据库字段、Redis GET／HGET、函数结果。
- 每个属性仅一份有效来源；切换保存替换旧配置，取消保留原值。
- 一对多来源缺少多行处理规则不能通过配置校验；取最新需处理并列时点。
- 模板参数随示例实例自动展开，未绑定占位符提示错误，不实际查询 Key。
- 移除被引用来源、连接或实现会显示依赖，不破坏引用。

### 链接与兼容

- 两端表和字段只能从对应对象已配置来源下拉，不接受手填。
- 切换表后旧字段清空；目标补充表可以追溯到目标实例身份。
- 数量关系冲突或目标唯一性未知明确提示，不任选匹配行。
- 当前真实项目草稿与已发布 v1 均可正常读取，旧字段和 computed 映射不丢失。
- 保存、发布、撤销和 409 冲突保护仍按现有双空间机制工作。
- 用户 ontology/ 数据不用于测试写入；测试使用独立临时目录与本地可控测试服务。

## 10. 原型的使用与限制

原型可操作连接新增／编辑／模拟测试、来源新增／编辑／删除、属性取值方式切换、模板展开和链接双端下拉。保存仅影响当前页面内存，刷新重置。

原型的连接测试有“成功／认证失败／超时”演示开关，仅用于展示界面状态。开发版本必须删除该开关，接入真实后端探测，不使用假延时结果模拟完成。

原型表名和字段、函数清单均为演示内容。正式来源配置不复制这些示例，也不自动新增单位对象或测试项目。原型的简化连接地址框应按第 4 节拆成真实配置字段。
